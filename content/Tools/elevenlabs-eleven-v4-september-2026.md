# ElevenLabs 發布 Eleven v4 與 v4 Turbo：史上最具表現力與低延遲的 TTS 模型

## 基本資訊

- 發布日期：2026-09-28
- 研究主題：音訊與語音 / Audio & Speech
- 主要來源：https://elevenlabs.io/blog/eleven-v4

## 概要

ElevenLabs 於 2026-09-28 同步發布 Eleven v4（最高品質表現力語音）與 Eleven v4 Turbo（~100 ms 中位數推理延遲、面向即時代理）兩大 TTS 基座模型，即時上線 ElevenAPI、ElevenAgents、ElevenCreative。v4 在 Artificial Analysis Provider Voice Arena 以 1319 Elo 奪冠，盲測約 75% 勝率；支援 90+ 語言、10 秒音頻即時克隆、專業聲音克隆。定價：v4 $0.08/千字元、Turbo $0.04/千字元，推出期享 72% 折扣至 2026-10-12。

## 核心價值

單一架構同時解決「極致表現力」與「即時低延遲」雙重需求，以統一 API 服務敘事級配音與語音代理雙場景，重新定義 TTS 商業化基準。

## 應用情境與實務影響

內容創作者可用 v4 產出電影級旁白、多角色有聲書；語音代理開發者採用 v4 Turbo 獲得 <150 ms 首語延遲，支援 WebSocket 串流、工具呼叫與 MCP 整合，大幅簡化端到端語音應用架構。
