# OpenAI 發布 GPT-6.1 Terra：兼具視覺推理與電腦操作的高性價比模型

## 基本資訊

- 發布日期：2026-10-26
- 研究主題：大型語言模型與自然語言處理 / LLM & NLP
- 主要來源：https://openai.com/index/introducing-gpt-6-1-terra

## 概要

OpenAI 於 2026-10-26 正式發布 GPT-6.1 Terra，定位為「快速、高效、低成本」的專業工作模型，支援圖像理解與精準電腦操作 (computer use)。API 定價為輸入 $1/M、快取輸入 $0.05/M、輸出 $5/M，較 GPT-5.6 Terra 降價 50%。在 Agents' Last Exam 基準上大幅超越前代，甚至以十分之一價格匹配 GPT-6 Astra 表現，任務完成速度提升 3 倍以上。即日起於 ChatGPT Work、Codex (Plus/Pro/Enterprise/Edu) 及 API (gpt-6.1-terra) 提供，並附帶系統卡與對齊改進說明。

## 核心價值

以極具競爭力的價格交付前沿級電腦操作能力，大幅降低代理式自動化部署門檻，推動「模型即服務」向實務落地邁進。

## 應用情境與實務影響

開發者可低成本串接 gpt-6.1-terra API 建構瀏覽器/桌面自動化、發票識別入帳、跨應用程式操作等代理工作流；企業用戶在 ChatGPT Work 獲得更高配額效率。

## 補充細節

官方部落格 2026-10-26 發文，同步於 X (Twitter) 宣傳、開發者社群公告、ChatGPT 學習中心更新；定價、模型 ID (gpt-6.1-terra)、基準數據 (Agents' Last Exam) 皆可驗證。
