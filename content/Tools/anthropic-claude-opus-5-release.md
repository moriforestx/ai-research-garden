# Anthropic 發布 Claude Opus 5：半價逼近 Fable 5 智能，新一代旗艦推理模型

## 基本資訊

- 發布日期：2026-07-23
- 研究主題：大型語言模型與自然語言處理 / LLM & NLP
- 主要來源：https://www.anthropic.com/news/claude-opus-5

## 概要

Anthropic 於 2026 年 7 月 23 日正式發布 Claude Opus 5，定位為「深思熟慮且主動」的旗艦模型，在編碼與知識工作評測（Frontier-Bench、GDPval-AA）上達到新 SOTA，性能逼近 Fable 5 但成本僅為其一半（$5/$25 每百萬 token，與 Opus 4.8 持平）。Opus 5 為 Claude Max 方案預設模型，也是 Claude Pro 方案上可用的最強模型。

## 核心價值

以 Opus 級定價提供近 Fable 級旗艦智能，大幅降低企業與開發者部署頂級推理模型的門檻。

## 應用情境與實務影響

已在所有方案上線（Max 預設、Pro 可選），整合於 Claude Code、Claude Platform、API（模型 ID：claude-opus-5）。新增「努力程度」調節，用戶可在單次請求中平衡智能深度與 token 成本。在 ARC-AGI 3、Zapier AutomationBench、OSWorld 2.0、HLE 等多項基準上以更低單任務成本超越競品。同步保持網路安全防護，標記請求回退至 Opus 4.8。

## 補充細節

模型支援 1M token 上下文視窗、128K 最大輸出。前部署評估顯示在生命科學（結構生物學、有機化學、生物資訊學）均優於 Opus 4.8，有機化學光譜推斷任務高出 10.2 個百分點、蛋白質功能預測高出 7.7 個百分點。早期存取客戶（Cognition、Cursor、Zapier、交易公司工程師）回報：Opus 5 能自行編寫電腦視覺管線從像素提取幾何、獨立建構測試驗證修復、單次會話完成全新交易所行情饋送整合。
