# Google 發布 Antigravity 2.0：代理優先的全棧開發平台，含桌面應用、CLI、SDK 與 Managed Agents

## 基本資訊

- 發布日期：2026-05-19
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://antigravity.google/blog/google-io-2026

## 概要

Google 於 2026/5/19 Google I/O 開發者大會發布 Antigravity 2.0，將原本的 AI 輔助編輯器重構為完整的代理式開發平台。核心組件：(1) 獨立桌面應用，支援多代理並行規劃、撰寫、執行與驗證代碼；(2) Go 語言編寫的 CLI 工具；(3) Antigravity SDK 供開發者構建自定義代理；(4) Gemini API 中的 Managed Agents 服務；(5) 原生 Android 應用構建支援。同步推出 $100/月 AI Ultra 方案，提供 5 倍配額。預設模型為 Gemini 3.5 Flash，亦相容 Claude Sonnet 4.5、GPT-OSS 等。

## 核心價值

從單一編輯器擴展為完整代理生態系統（桌面/CLI/SDK/API/行動端），標誌 Google 正式佈局生產級代理式軟體工程基礎設施。

## 應用情境與實務影響

開發者可在本地並行執行多代理完成多日工程任務；SDK 允許將代理整合至既有 CI/CD；Managed Agents 降低自建基礎設施門檻；Android CLI 讓代理直接操作 Android Studio 功能（語義分析、Compose 預覽、UI 測試）。

## 補充細節

Antigravity 1.0 於 2025/11/18 隨 Gemini 3 發布；2.0 為完全重寫。消費者版 Gemini CLI 於 2026/6/18 停止服務，企業版保留。官方部落格：https://antigravity.google/blog/google-io-2026；TechCrunch、The Next Web 均有報導。
