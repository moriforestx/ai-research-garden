# Microsoft Agent Framework 1.0 GA：統合 AutoGen 與 Semantic Kernel，原生支援 MCP 與 A2A

## 基本資訊

- 發布日期：2026-04-03
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-version-1-0

## 概要

Microsoft 於 2026 年 4 月 3 日發布 Microsoft Agent Framework (MAF) 1.0 正式版，為 .NET 與 Python 提供統一的開源 SDK 與執行時。此版本完成 AutoGen 與 Semantic Kernel 的融合，內建 Model Context Protocol (MCP) 與 Agent-to-Agent (A2A) 協定支援，提供聊天客戶端、工具、MCP 整合、上下文提供者、中介軟體與多步驟工作流等原語。同步釋出 GitHub Copilot SDK 整合、CodeAct 模式（多步驟負載較傳統接線減少 52% 時間、64% token）、Agent Harness、Hosted Agents 等生產級功能。MIT 授權，支援多模型供應商、Ollama/ONNX 本地模型。

## 核心價值

首個統一 .NET/Python、原生 MCP+A2A、企業級支援的代理框架 GA 版

## 應用情境與實務影響

企業可單一框架建構跨語言、跨模型、可審計的多代理系統；AutoGen 使用者獲得明確遷移路徑與長期支援承諾

## 補充細節

RC1 於 2 月 19 日釋出，GA 版 API 穩定並承諾長期支援。BUILD 2026 另宣佈 Agent Harness、Hosted Agents、CodeAct 等進階功能。專案位於 github.com/microsoft/agent-framework。
