# OpenAI 發布 GPT-6 Astra：宣稱達到人工通用智能

## 基本資訊

- 發布日期：2026-09-04
- 研究主題：大型語言模型與自然語言處理 / LLM & NLP
- 主要來源：https://openai.com/index/gpt-6-astra/

## 概要

OpenAI 於 2026 年 9 月 4 日正式發布 GPT-6 Astra，並稱其為人工通用智能（AGI）。GPT-6 系列包含 Astra（旗艦版）、Sol 與 Luna（較小版本，9 月 22 日釋出），以及 Instant（10 月 8 日釋出，具備互動式 UI 元件）。Astra 為多模態模型，支援文本、圖像與程式碼，API 定價為每百萬輸入 token 10 美元、輸出 token 50 美元。此版本標誌著 OpenAI 從 GPT-5.6 的重大架構升級。

## 核心價值

OpenAI 首度公開宣稱其模型達到 AGI 級別，引發學術界與產業界關於 AGI 定義與驗證標準的廣泛討論。

## 應用情境與實務影響

企業與開發者可透過 API 存取更強大的推理與多模態能力；Instant 版本的互動式 UI 降低非技術用戶門檻。定價策略反映高階模型算力成本。

## 補充細節

GPT-6 Astra 穩定版於 2026-09-04 公開釋出；GPT-6 Sol/Luna 於 2026-09-22 釋出；GPT-6 Instant 於 2026-10-08 向付費用戶開放。官方部落格：https://openai.com/index/gpt-6-astra/。Wikipedia 記載發布時間線與定價資訊。
