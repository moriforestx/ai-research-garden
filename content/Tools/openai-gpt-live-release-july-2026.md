# OpenAI 推出 GPT-Live 全雙工語音模型，支援同時聽說與即時翻譯

## 基本資訊

- 發布日期：2026-07-08
- 研究主題：音訊與語音 / Audio & Speech
- 主要來源：https://openai.com/index/introducing-gpt-live

## 概要

OpenAI 於 2026 年 7 月 8 日正式發布 GPT-Live，新一代全雙工語音模型家族，包含 GPT-Live-1 與 GPT-Live-1 mini 兩個版本，同步在 ChatGPT Voice 全球上線。全雙工架構使模型能同時聽取與生成語音，支援自然的來回對話、即時回應確認（如「嗯」、「好」）、即時翻譯等能力。7 月 31 日更新：API 產出的語音新增 SynthID 水印與公開驗證工具，提供來源溯源機制。

## 核心價值

首個大規模部署的全雙工語音模型，將語音互動從「輪流講話」推進為「自然對話」，並內建水印溯源，為語音代理人應用與內容真實性驗證建立新基準。

## 應用情境與實務影響

開發者可透過 ChatGPT Voice 直接體驗；語音代理人、即時翻譯、無障礙輔助等場景受益於低延遲雙向串流；SynthID 水印與驗證 API 解決 AI 生成語音濫用與深偽造疑慮，企業可整合來源檢查到合規流程。

## 補充細節

架構創新：全雙工設計打破傳統 TTS+ASR 串接模式，單一模型端到端處理音訊串流。功能亮點：即時回應確認、打斷處理、語速自適應、即時翻譯。部署：ChatGPT Voice 率先接入，API 面向開發者開放（具體模型 ID 為 gpt-live-1、gpt-live-1-mini）。安全：SynthID 水印不可聽感知嵌入，公開驗證工具與 API 同步上線。競品參考：Google Gemini Live、Meta Spirit LM、ElevenLabs Conversational AI。來源：OpenAI 官方部落格、Reuters 報導、OpenAI X 官方貼文、CNBC 報導、OpenAI 研究發布頁面。
