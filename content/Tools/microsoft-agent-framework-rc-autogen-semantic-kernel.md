# Microsoft Agent Framework 達到 Release Candidate：統合 AutoGen 與 Semantic Kernel

## 基本資訊

- 發布日期：2026-02-19
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://devblogs.microsoft.com/agent-framework/migrate-your-semantic-kernel-and-autogen-projects-to-microsoft-agent-framework-release-candidate

## 概要

微軟於 2026 年 2 月 19 日宣布 Microsoft Agent Framework 達到 Release Candidate 階段（.NET 與 Python 同步），正式統合企業級的 Semantic Kernel 基礎與 AutoGen 的創新編排能力。RC 版本意味著 API 介面穩定、1.0 版規劃功能完備，開放社群測試反饋，預計數週內發布 GA 正式版。

## 核心價值

首個將企業級核心與多代理編排統一的開源 SDK，提供圖工作流、A2A/MCP 協定、檢查點、串流與人機介入模式。

## 應用情境與實務影響

現有 AutoGen 與 Semantic Kernel 用戶獲得明確遷移路徑；企業可採用單一框架滿足從原型到生產環境的完整代理開發需求。

## 補充細節

官方部落格由 Dmytro Struk 發布。GitHub 上 Python 1.0.0-rc1 於同日釋出，NuGet (.NET) 與 PyPI (Python) 均可安裝。後續 1.0 GA 版已於 2026 年中發布。
