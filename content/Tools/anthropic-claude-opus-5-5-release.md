# Anthropic 發布 Claude Opus 5.5，效能媲美 Fable 5.1 且成本降 40%

## 基本資訊

- 發布日期：2026-09-22
- 研究主題：大型語言模型與自然語言處理 / LLM & NLP
- 主要來源：https://www.anthropic.com/claude-opus-5-5

## 概要

Anthropic 官方宣布推出 Claude Opus 5.5，作為新 Claude 5.5 系列首款模型。官方聲稱其在多項基準測試達到 Claude Fable 5.1 級別效能，但運行成本較 Opus 5 降低 40%（輸入 $4/MTok、輸出 $20/MTok）。模型具備 1M token 上下文窗口、128K 最大輸出、持續開啟思考模式，並導入「保留思考」防蒸餾機制，禁止 API 使用者編輯先前上下文以提取推理過程。

## 核心價值

頂級實驗室主動降低旗艦模型價格並強化防蒸餾防護，顯示商業化階段進入「效能平權、安全先行」新常態。

## 應用情境與實務影響

開發者可以更低成本獲得頂級編碼與知識工作能力；需注意四項破壞性變更遷移現有 Opus 5 代碼。Sonnet 5.5 與 Haiku 5.5 將於數週內跟進。

## 補充細節

發布日期為 2026-09-22，模型 ID 為 `claude-opus-5-5`。定價：標準模式輸入 $4/MTok、輸出 $20/MTok；快速模式輸入 $8/MTok、輸出 $40/MTok。批次 API 輸入 $2/MTok、輸出 $10/MTok。提示快取讀取 $0.20/MTok（輸入成本 5%）。Anthropic CEO Dario Amodei 先前發文表示將「放緩能力推進速度以配合對齊進度」。
