# Claude Code Templates

## 這是什麼

針對 Anthropic Claude Code CLI 的專案模板集合，提供開箱即用的專案結構、配置、腳本和最佳實踐，幫助開發者快速啟動 AI 輔助開發工作流。由社區維護，涵蓋 Web 應用、API 服務、CLI 工具、數據管道、AI Agent 等多種專案類型。

## 主要功能

- 預配置的專案模板：Next.js、FastAPI、React Native、Electron、Python CLI、Rust、Go 等
- Claude Code 專用配置：`.claude/` 目錄包含指令、權限、環境變量、MCP Server 配置
- 開發工作流腳本：測試、構建、部署、代碼審查、文檔生成的自動化腳本
- 最佳實踐文檔：提示工程模式、上下文管理策略、多文件編輯技巧
- 範例專案：完整的 TODO App、RAG 系統、多 Agent 協作、代碼遷移等實戰案例

## 為什麼重要

- Claude Code 作為新一代 AI 編碼助手，缺乏官方標準化專案模板
- 解決「空白頁問題」：新專案啟動時不知如何配置 Claude Code 以發揮最大效用
- 標準化團隊協作：統一專案結構降低團隊成員切換專案的認知負擔
- 加速 AI 原生開發流程採用：將最佳實踐固化為模板，避免每個團隊重複探索

## 可能影響

- 成為 Claude Code 生態的事實標準模板庫
- 推動其他 AI 編碼工具（Cursor、Windsurf、GitHub Copilot）建立類似模板生態
- 影響企業級 AI 開發平台的專案初始化功能設計
- 可能催生「模板市場」：專業模板作為商業產品分發
