# Meta 發布 Muse Spark 1.3 多模態推理模型

## 基本資訊

- 發布日期：2026-09-02
- 研究主題：電腦視覺 / Computer Vision
- 主要來源：https://ai.meta.com/research/blog/introducing-muse-spark-1-3/

## 概要

Meta Superintelligence Labs 於 2026 年 9 月 2 日發布 Muse Spark 1.3，為閉源多模態推理模型，支援文字、圖像與視訊輸入，擁有 1M token 上下文窗口。基準測試顯示：DeepSWE 1.1 端到端代理軟體工程 75.4%、Terminal-Bench 2.1 88.8%、SWEAtlas CodeBase QnA 59.4%、長上下文檢索 (MRCR) 98.5%。模型即時上線 Muse Code（Meta 代碼代理）與 Meta Model API，定價 $1.25/百萬輸入、$4.25/百萬輸出 token，為同級模型約一半成本。

## 核心價值

Meta 以閉源策略推出專為長跨度代理與編碼工作流優化的多模態前沿模型，並在長上下文檢索上達到近完美表現，同時大幅降低 API 成本。

## 應用情境與實務影響

開發者可透過 Muse Code 或 Model API 直接替換模型 ID 即可獲得更強的代理編碼與多模態推理能力；企業級工作負載成本顯著下降。

## 補充細節

同屬 Muse 系列的 Muse Glimmer（開放權重版本）與 Muse Image/Video 於 2026 年稍早發布；Spark 1.3 為專有權重版本，針對代理任務深度優化。Meta AI 官網與研究部落格均於 9 月 2 日同步上線公告與安全準備報告。
