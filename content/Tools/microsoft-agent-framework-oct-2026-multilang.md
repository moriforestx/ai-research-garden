# Microsoft Agent Framework 10 月多語言穩定版釋出

## 基本資訊

- 發布日期：2026-10-14
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://www.nuget.org/packages/Microsoft.Agents.AI.Harness/1.25.0

## 概要

Microsoft Agent Framework 於 2026 年 10 月釋出跨語言穩定版本：.NET 套件 Microsoft.Agents.AI.Harness 1.25.0（10/14）、Python agent-framework 1.22.0（10/15）、Go github.com/microsoft/agent-framework-go v0.1.1（10/13）。框架於 2026-04-02 達 v1.0 GA，融合 Semantic Kernel 與 AutoGen 為統一 SDK，支援圖式編排、耐久執行、人工審核暫停、MCP、OpenTelemetry、CodeAct、GitHub Copilot/Claude Agent SDK 連接器、Azure Foundry 託管代理。MIT 授權，GitHub 開源。

## 核心價值

企業級代理框架完成多語言（.NET/Python/Go）同步穩定釋出，內建生產級運行時與治理能力，確立 Azure 生態系代理開發標準。

## 應用情境與實務影響

企業可直接採用受支援的 Harness 運行時與 Foundry 託管服務，避免自建編排層；MCP 與連接器生態加速多模型、多工具整合；OpenTelemetry 內建可觀測性滿足合規需求。
