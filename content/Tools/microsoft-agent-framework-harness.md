# Microsoft Agent Framework Harness：代理人運行時正式釋出

## 基本資訊

- 發布日期：2026-07-22
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://devblogs.microsoft.com/agent-framework/the-microsoft-agent-framework-harness-is-now-released

## 概要

Microsoft 於 2026 年 7 月 22 日在官方 DevBlog 發布《The Microsoft Agent Framework Harness is now released》，宣布 Agent Framework Harness 正式釋出。Harness 為生產級代理人運行時，內建循環控制、規劃、記憶、上下文管理、人工審核與遙測，支援 Python 與 .NET。此版本標誌著從「構建代理人的 SDK」轉向「運行與治理代理人的平台」。8 月 3 日 Harness 與 Foundry Hosted Agents 雙雙達到 GA，提供工具路由、歷史持久化、上下文壓縮、審核工作流、OpenTelemetry 觀測等企業級能力。

## 核心價值

首個主流雲廠商推出的生產級代理人運行時，統一 Semantic Kernel 與 AutoGen 架構，確立圖基執行、人工介入、MCP 工具存取為行業標準架構。

## 應用情境與實務影響

企業可直接在 Azure AI Foundry 部署受管代理人，享有沙箱執行、身分管理、記憶隔離、可觀測性；降低從原型到生產的工程門檻，加速代理式應用落地。

## 補充細節

官方部落格由首席工程師 Wes Steyn 撰寫，發布日期 2026-07-22。InfoQ 於 2026-08-03 報導 GA 里程碑。Build 2026 (6/2-3) 已預覽 Harness、Hosted Agents、CodeAct。版本 1.0 SDK 於 4/2 釋出，Harness 於 7/22 釋出，8/3 達 GA。
