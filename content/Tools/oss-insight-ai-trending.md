# OSS Insight AI Trending

## 這是什麼

OSS Insight 提供的 GitHub AI 領域實時熱門倉庫排名系統。按星標增長速度、總星標數、Fork 數等多維度對 AI Agent 框架、LLM 工具、MCP Server、編碼 Agent、RAG 框架、推理引擎、向量資料庫、Vibe Coding 工具、AI 編碼助手等九大類別進行即時排名。

## 主要功能

- 即時追蹤 GitHub 上 AI 相關倉庫的星標增長趨勢
- 按技術棧分類：AI Agents、LLM Tools、MCP Servers、Coding Agents、RAG Frameworks、Inference Engines、Vector Databases、Vibe Coding Tools、AI Coding Assistants
- 提供倉庫詳細指標：星標數、Fork 數、Issue 數、貢獻者數、許可證、最近提交時間
- 支援按日、週、月、季、年多時間窗口查看趨勢
- 內建集合功能，可查看特定主題（如 AI Agent Frameworks）的綜合排名

## 為什麼重要

作為開源 AI 生態的「風向標」，幫助開發者、投資人、技術決策者：
- 發現新興工具和技術趨勢（如早期發現 Langflow、Dify、Agent Skills 等爆發式增長專案）
- 技術選型參考：對比同類工具的社區活躍度和採用度
- 人才畫像：了解市場上最熱門的技術棧，指導招聘和技能培訓
- 競品分析：監控競爭對手開源項目的發展軌跡

## 可能影響

- 成為 AI 基礎設施選型的標準參考工具之一
- 推動開源項目在文檔、示例、社區運營上投入更多資源以提升排名
- 可能催生基於趨勢數據的自動化技術雷達產品
