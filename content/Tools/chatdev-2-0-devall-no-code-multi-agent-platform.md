# ChatDev 2.0 (DevAll)：面向異構多代理系統的無代碼平台

## 基本資訊

- 發布日期：2026-09-01
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://arxiv.org/abs/2609.00714

## 概要

ChatDev 2.0 (DevAll) 為無代碼平台，支援異構多代理系統 (MAS) 的建構、執行與檢查。核心創新：宣告式可執行圖抽象搭配感知循環的執行引擎，使異構代理與動態循環交互可在單一框架表示執行；整合視覺介面支援人在回路步驟，無需撰寫代碼即可編寫、運行、監控、檢查 MAS。實驗證明 DevAll 能以具競爭力效能復現三項代表性任務的 SOTA MAS，且無需任務專用編排代碼。代碼開源於 github.com/OpenBMB/ChatDev。

## 核心價值

首個以宣告式圖抽象統一表達力與易用性的無代碼 MAS 平台，解決代碼框架工程負擔大與無代碼工具表達力受限的雙重困境。

## 應用情境與實務影響

領域專家可直接構建複雜多代理應用而無需程式設計；研究者可快速原型驗證 MAS 架構；企業可降低 AI 代理應用開發門檻與維護成本。
