### OpenAI 發布 GPT-6.1 Terra：大幅降低成本、提升電腦操作能力

- 🗂 內容類型：技術動態與落地 / Technical Developments & Applications
- 📅 發布日期：2026-10-26
- 🕒 收錄時距發布：23 天
- 🔗 主要來源：https://openai.com/index/introducing-gpt-6-1-terra
- 📊 綜合評分（AI 判斷）：4.5 / 5
- 🧠 內容摘要：OpenAI 於 2026 年 10 月 26 日正式發布 GPT-6.1 Terra，這是 GPT-6 系列中主打高性價比與電腦操作能力的模型。標準 API 定價為每百萬輸入 token 1 美元、每百萬輸出 token 5 美元，較 GPT-5.6 Terra 降低 50%。GPT-6.1 Terra 在 Agents' Last Exam 測試中大幅超越 GPT-5.6 Terra，且以十分之一價格達到 GPT-6 Astra 同等水準，任務完成速度更快 3 倍以上。已向 Plus、Pro、Enterprise、Edu 用戶在 ChatGPT Work 和 Codex 中開放，開發者可透過 API 以 gpt-6.1-terra 存取。
- 📌 核心價值：以大幅降低的成本提供頂級電腦操作與視覺推理能力，讓高頻率自動化任務（如發票處理、資料輸入）在經濟上可行。
- 🌍 應用情境與實務影響：開發者可用更低成本部署大規模電腦操作代理；企業用戶在 ChatGPT Work 中獲得更高效的視覺推理與跨應用操作模型。
- 🗂 知識庫連結：[[TechnicalDevelopments/openai-gpt-6-1-terra]]
## 電腦視覺 / Computer Vision

### ReactionBench: A Human-Anchored Benchmark for Modeling Reactions to Video

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-10-11
- 🕒 收錄時距發布：38 天
- 🔗 主要來源：https://arxiv.org/abs/2611.00050
- 📊 綜合評分（AI 判斷）：4.5 / 5
- 🧠 內容摘要：ReactionBench 是一個針對反應特定視頻理解的人類錨定基準，從 31,834 個同步刺激-反應片段（跨越 433 小時、八個領域）構建，評估三種互補能力：排序觀看者反應強度、將反應匹配到其時序對齊的刺激、以及解釋與該反應相關的具體刺激線索。人類標註提供了 14,894 個評分，覆蓋 3,257 個時刻。在七個多模態模型中，最佳模型在四向刺激-反應匹配上達到 50.9% 準確率，而 GPT-5 在反應替換下無可檢測性能損失。
- 📌 核心價值：首個系統性評估多模態模型將觀察者反應錨定於刺激脈絡的基準，揭示現有模型在反應特定接地上的根本缺口。
- 🌍 應用情境與實務影響：為社交回應式多模態系統、情感計算、人機互動提供標準化評估框架；推動模型從「理解視頻發生什麼」進化到「理解人如何回應」。
- 🗂 知識庫連結：[[Papers/reactionbench-human-anchored-video-reaction-benchmark]]
## 大型語言模型與自然語言處理 / LLM & NLP

### MEMENTO: Learning Context Management for Long Context Processing Agents

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-10-30
- 🕒 收錄時距發布：19 天
- 🔗 主要來源：https://arxiv.org/abs/2611.00244
- 📊 綜合評分（AI 判斷）：4.8 / 5
- 🧠 內容摘要：MEMENTO 是一個基於 Qwen3-8B 的長上下文代理，透過上下文壓縮學習管理上下文。研究發現現成代理模型（含 GPT-5.5、GLM-5.3）常撰寫無效筆記，且單純 RL 難發現有用的記筆行為。MEMENTO 先以合成軌跡微調啟動記筆能力，再用結合答案正確性、筆記品質啟發式、信心校準的獎勵進行 RL 強化。僅在 20K tokens 上下文窗口下，於四個書級問答基準（最長 2.5M tokens）將 Qwen3-8B 準確率從 36.9% 提升至 67.8%，超越同環境下的 GPT-5.5 agent (13.1%) 及全書上下文 (56.7%)，成本不足 1/50；亦接近 100x 更大的 GLM-5.3 agent (69.3%)，成本僅 1/9。
- 📌 核心價值：證明小模型經過專門的上下文管理訓練，能以極低成本在長文本任務上媲美甚至超越超大模型，為長上下文代理架構提供新範式。
- 🌍 應用情境與實務影響：大幅降低長文本處理（法律文檔、代碼庫、書籍、醫療記錄）的計算成本；為資源受限環境部署長上下文代理提供可行路徑。
- 🗂 知識庫連結：[[Papers/memento-long-context-agent-management]]
## 音訊與語音 / Audio & Speech

### One Waveform, Two Stories: Benchmarking Speech-Acoustic Conflict in Audio-Language Models

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-10-30
- 🕒 收錄時距發布：19 天
- 🔗 主要來源：https://arxiv.org/abs/2611.00325
- 📊 綜合評分（AI 判斷）：4.6 / 5
- 🧠 內容摘要：引入 SAC-Bench，首個針對音頻-語言模型（ALM）中「語音主張與聲學證據衝突」的基準。從 188 類聲音事件構建 616,031 個獨特片段，涵蓋七個語義、時序、空間任務，配對兼容/矛盾的合成語音主張及純音頻對照。五個開放權重 ALM 測試顯示：純音頻高準確率常與衝突條件下的大幅性能下降並存；事件身份辨識在衝突條件下下降 24.8–46.5 個百分點；時序任務失敗甚至在語音跟隨完整事件序列後仍持續；空間案例研究發現語音主張與語音源物理軌跡均降低運動準確率。提示干預有時恢復聲學準確率，但也可能在不改善接地情況下減少主張對齊答案或惡化表現。
- 📌 核心價值：系統性揭示 ALM 在語音-聲學衝突下的脆弱性，區分聲學能力、衝突魯棒性與干預效果三個維度，為可信賴多模態音頻理解奠基。
- 🌍 應用情境與實務影響：推動音頻-語言模型從「聽懂內容」進化到「在衝突證據中堅持事實」；對語音助理、內容審核、自動駕駛音頻感知等安全關鍵應用具指導意義。
- 🗂 知識庫連結：[[Papers/sac-bench-speech-acoustic-conflict-alm]]
## AI 代理人 / AI Agents

### Measuring AI Agents as Teammates with Collaborative Intelligence

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-11-02
- 🕒 收錄時距發布：16 天
- 🔗 主要來源：https://arxiv.org/abs/2611.02633
- 📊 綜合評分（AI 判斷）：4.7 / 5
- 🧠 內容摘要：提出 Collaborative Intelligence Benchmark，首個系統性測量 AI 代理作為隊友能力的基準。包含 240 個任務，跨越 8 個團隊合作維度（拒絕不安全捷徑、檢查較弱模型遺留工作等），任務源自真實記錄（航空事故報告、臨床案例、編碼任務、談判等）且具程式化可驗證結果。為隔離團隊合作與個體能力，模型僅在能獨自解決的任務上評分。評測 18 個閉源/開放權重模型發現：所有模型在隊友角色上皆有明顯弱點，最佳模型僅得 82.2/100。前沿模型幾乎都能拒絕不安全捷徑、舉報不當行為，但在人際壓力下妥協（衝突中僅 14% 達最佳協議），接手作弊較弱模型任務時通過率從 97% 跌至 81%。關鍵發現：一般能力不保證良好團隊合作，能力近似模型隊友得分相差高達 11 分。基準包含 160 公開任務與代碼/數據，另 80 任務保留評測。
- 📌 核心價值：將「團隊合作智能」形式化為可測量、可基準化的能力，揭示前沿模型在協作中的系統性盲點，為多代理系統安全部署提供關鍵評估維度。
- 🌍 應用情境與實務影響：指導多代理系統（科研協作、程式設計、醫療決策、談判代理）的設計與評測；推動從「單模型能力」向「協作智能」的範式轉移。
- 🗂 知識庫連結：[[Papers/collaborative-intelligence-ai-agent-teammate-benchmark]]
## AI 應用與部署 / AI Applications & Deployment

### Rethinking KV Cache Eviction for Agentic LLM Serving

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-10-30
- 🕒 收錄時距發布：19 天
- 🔗 主要來源：https://arxiv.org/abs/2611.00391
- 📊 綜合評分（AI 判斷）：4.6 / 5
- 🧠 內容摘要：針對代理型 LLM 服務系統的 KV 快取記憶體壓力問題，提出 Penelope 系統。現有機制通常從序列兩端驅逐 KV 以保留前綴共享，但代理工作負載會跨多輪重複重用長歷史。重新計算序列末端附近 token 的 KV 快取成本顯著高於早期 token（因注意力計算涉及更長歷史）。Penelope 策略：保留共享前綴，從剩餘歷史開頭驅逐 KV 快取同時保留快取後綴。聯合設計驅逐策略、KV 重計算與統一 GPU-CPU 兩層快取管理。在 SGLang 實作，於三種 Qwen3 模型規模用真實代理軌跡評測：僅 GPU 快取下 mean TTFT 降至多 60%、作業完成時間降至多 37%；雙層 GPU-CPU 快取下分別降至多 76% 與 60%。
- 📌 核心價值：首個針對代理工作負載特徵（長歷史重用、末端重計算昂貴）優化的 KV 快取驅逐與多層管理方案，大幅降低代理型 LLM 服務延遲。
- 🌍 應用情境與實務影響：直接適用於生產級代理服務平台（SGLang、vLLM 等），減少 GPU 記憶體壓力、降低服務成本、提升多輪對話代理的響應速度。
- 🗂 知識庫連結：[[Papers/penelope-kv-cache-eviction-agentic-llm-serving]]
