## 音訊與語音 / Audio & Speech

### Mistral 發布 Voxtral TTS：開放權重、支援零樣本語音克隆的多語言語音合成模型

- 🗂 內容類型：工具與專案 / Tools & Projects
- 📅 發布日期：2026-03-26
- 🕒 收錄時距發布：141 天
- 🔗 主要來源：https://siliconangle.com/2026/03/26/mistral-releases-open-weights-speaking-ai-model-voxtral-tts
- 📊 綜合評分（AI 判斷）：4.2 / 5
- 🧠 內容摘要：Mistral AI 於 2026 年 3 月 26 日正式發布 Voxtral TTS，為其首個文字轉語音模型，採開放權重釋出 (open-weights)，模型參數量 40 億，支援 9 種語言 (英、法、德、西、荷、葡、義、印地、阿拉伯)。核心亮點為零樣本語音克隆：僅需 3 秒參考音訊即可捕捉聲音細節 (口音、語調、語氣詞、停頓)。人類評測中，自然度超越 ElevenLabs Flash v2.5，媲美 ElevenLabs v3。延遲極低：500 字符輸入下模型層面 70ms。定價 $16/百萬字符，約為 ElevenLabs 的 1/4 至 1/7。同步釋出 Voxtral Transcribe (STT) 系列，構建端到端語音管線。
- 📌 核心價值：開放權重 + 3 秒零樣本克隆 + 9 語言 + $16/M 字符，大幅降低企業級語音應用門檻。
- 🌍 應用情境與實務影響：企業可自建語音堆疊、避免資料外洩、依需求微調；適用客服路由、跨國銷售即時翻譯、工業語音介面、金融合規錄音等場景。OpenClaw 社群已提出整合需求 (Issue #58117)。
- 🗂 知識庫連結：[[Tools/mistral-voxtral-tts]]

### Google 發布 ADK for Java 1.0.0：正式支援 Java 生態系的 AI 代理人開發框架

- 🗂 內容類型：工具與專案 / Tools & Projects
- 📅 發布日期：2026-03-30
- 🕒 收錄時距發布：137 天
- 🔗 主要來源：https://developers.googleblog.com/announcing-adk-for-java-100-building-the-future-of-ai-agents-in-java
- 📊 綜合評分（AI 判斷）：4.3 / 5
- 🧠 內容摘要：Google 於 2026 年 3 月 30 日在官方開發者部落格宣布 ADK for Java 1.0.0 正式發布，將 Agent Development Kit (ADK) 擴展至 Java 生態系。ADK 是 Google 開源的 AI 代理人開發框架，提供會話管理、瀏覽器除錯介面 (ADK Web)、程式碼執行支援、CLI 工具 (`adk run`, `adk api_server`)，並支援部署至 Cloud Run、GKE、Vertex AI Agent Engine。Java 版本的 GA 釋出標誌著 ADK 多語言支援的重要里程碑，讓 Java 企業開發者能以原生方式建構、除錯與部署生產級 AI 代理人。
- 📌 核心價值：ADK 正式支援 Java，完善多語言生態 (Python、Go、Java)，降低企業級代理人應用的採用門檻。
- 🌍 應用情境與實務影響：Java 企業開發團隊可直接使用 Maven/Gradle 整合 ADK，利用現有 Spring Boot、Quarkus 等技術棧快速建構具備會話管理、工具呼叫、多代理人協作的應用，並一鍵部署至 Google Cloud 基礎設施。
- 🗂 知識庫連結：[[Tools/google-adk-for-java-1-0-0]]

- 🗂 內容類型：技術動態與落地 / Technical Developments & Applications
- 📅 發布日期：2026-04-22
- 🕒 收錄時距發布：114 天
- 🔗 主要來源：https://cloud.google.com/blog/topics/google-cloud-next/welcome-to-google-cloud-next26
- 📊 綜合評分（AI 判斷）：4.6 / 5
- 🧠 內容摘要：Google 於 2026 年 4 月 22 日在 Cloud Next 2026 開幕主題演講中正式發布 Gemini Enterprise Agent Platform，將 Vertex AI 重新品牌化並整合為統一的企業級 AI 代理人平台。該平台整合模型選擇、建構與調校服務 (Vertex AI)、代理人開發套件 (ADK)、低代碼視覺建構器 (Agent Studio)、受控執行環境 (Agent Engine)、持久記憶體 (Memory Bank)、跨對話會話管理、企業級治理、觀測性、代理人身分管理與 A2A 多代理人協作市集，提供端到端的建構、部署、治理與擴展工作區。同步吸收 Google Agentspace 為統一的 Gemini Enterprise 體驗，支援 200+ 基礎模型 (含 Gemini、Claude、第三方模型)。
