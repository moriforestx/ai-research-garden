- 🗂 內容類型：技術動態與落地 / Technical Developments & Applications
- 📅 發布日期：2026-07-09
- 🕒 收錄時距發布：37 天
- 🔗 主要來源：https://www.microsoft.com/en-us/research/blog/aurora-1-5-extending-open-foundation-models-for-weather-and-earth-system-applications
- 📊 綜合評分（AI 判斷）：4.5 / 5
- 🧠 內容摘要：Microsoft Research 發布 Aurora 1.5，為開放的 Aurora 地球系統基礎模型重大擴展版本。新增 22 個與能源、農業、運輸及氣候風險相關的天氣變數，支援逐小時時間解析度與機率式集合預測。模型開源於 GitHub，檢查點發布於 Hugging Face，可供研究人員與開發者使用、評估與延伸。
- 📌 核心價值：開放原始碼的地球系統基礎模型重大升級，大幅擴展預測變數與時間解析度，並新增集合預測能力，降低 AI 天氣預測門檻。
- 🌍 應用情境與實務影響：研究機構與企業可直接部署或微調 Aurora 1.5 進行高解析度天氣預測、氣候風險評估、再生能源發電預測等應用，無須從頭訓練大型模型。

## 電腦視覺 / Computer Vision

### Embodied.cpp：異構機器人上具身 AI 模型的可移植推理運行時

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-07-03
- 🕒 收錄時距發布：43 天
- 🔗 主要來源：https://arxiv.org/abs/2607.02501
- 📊 綜合評分（AI 判斷）：4.3 / 5
- 🧠 內容摘要：來自 SEU-PAISys 與 TII 的研究團隊發布 Embodied.cpp，一個面向 Vision-Language-Action (VLA) 與 World-Action Models (WAM) 的輕量級 C++ 推理運行時。透過五層模組化架構（輸入適配器、序列構建器、骨幹執行、頭部插件、部署適配器），支援 CPU/CUDA GPU/NPU 異構硬體上的批次大小 1 高效推理，模型權重採用 GGUF 格式，記憶體佔用從 200+ MiB 壓縮至 88 MiB，並開源於 GitHub (Apache 2.0)。
- 📌 核心價值：首個專為具身 AI 設計的跨平台 C++ 推理運行時，解決 VLA/WAM 模型在邊緣機器人上部署的延遲與記憶體瓶頸，並提供統一介面支援多種主流模型架構。
- 🌍 應用情境與實務影響：機器人開發者可直接將 Pi0、OpenVLA、GR-1 等主流具身模型部署到資源受限的邊緣裝置（Jetson Orin、RK3588、Intel NPU 等），無需依賴 Python 深度學習框架，大幅降低實機部署門檻。
- 🗂 知識庫連結：[[Papers/embodied-cpp-portable-inference-runtime]]
## 大型語言模型與自然語言處理 / LLM & NLP

### 從專有 LLM API 竊取推理軌跡：客戶端加密推理的安全性漏洞

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-08-10
- 🕒 收錄時距發布：5 天
- 🔗 主要來源：https://arxiv.org/abs/2608.09867
- 📊 綜合評分（AI 判斷）：4.6 / 5
- 🧠 內容摘要：Panfilov 等人發現主流專有 LLM API（Anthropic、OpenAI、Google）的客戶端加密推理軌跡存在嚴重漏洞：加密區塊可跨會話、跨用戶、甚至跨同提供商旗下不同模型重放。較弱、防護較少的模型可作為解密神諭，還原出更強模型的隱藏推理過程。作者投入約 3 萬美元 API 費用實測，確認可導致未授權模型蒸餾、密鑰提取、越獄與隱形提示注入。各大廠於 2026 年 8 月初完成緩解修補。
- 📌 核心價值：首次系統性證明推理模型的「思維鏈」客戶端加密在實務上可被繞過，揭示提供商間共用加密金鑰的架構級風險，對 LLM 供應鏈安全與推理隱私構成根本性挑戰。
- 🌍 應用情境與實務影響：企業若使用具推理能力的閉源 API 處理敏感資料，需評估推理軌跡外洩風險；研究者應關注推理加密協定的標準化與正式驗證。論文同步發布再現網站 stolen-thoughts.com 供學術驗證。
- 🗂 知識庫連結：[[Papers/stealing-reasoning-traces-proprietary-llm-apis]]
## 音訊與語音 / Audio & Speech

### Speech LLMs are Contextual Reasoning Transcribers：引入思維鏈推理的語音辨識新範式

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-04-01
- 🕒 收錄時距發布：136 天
- 🔗 主要來源：https://arxiv.org/abs/2604.00610
- 📊 綜合評分（AI 判斷）：4.4 / 5
- 🧠 內容摘要：Microsoft Core AI 團隊提出 CoT-ASR（Chain-of-Thought ASR），讓大型語言模型在語音辨識過程中先產生情境推理鏈，再輸出逐字稿。透過 CTC non-blank token 機率加權 LLM embedding 的 CTC-weighted LLM Adapter，有效對齊語音編碼器輸出與 LLM 文字潛在空間。實驗顯示相較標準 LLM-based ASR，CoT-ASR 字錯率 (WER) 相對降低 8.7%、實體錯誤率 (EER) 相對降低 16.9%，並在語音翻譯、口語問答等下游任務展現泛化能力。
- 📌 核心價值：首次將思維鏈推理引入端到端語音辨識，證明 LLM 內建的生成式推理能力可顯著提升 ASR 準確度，特別是實體識別等需語境理解的場景。
- 🌍 應用情境與實務影響：語音助理、會議紀錄、醫療口述等對專有名詞準確度敏感的應用可直接受益；CTC-weighted Adapter 為無需重新訓練語音編碼器即可接入新 LLM 提供實作路徑。
- 🗂 知識庫連結：[[Papers/speech-llms-contextual-reasoning-transcribers-cot-asr]]

### 持續改進與並行自主探索：面向大規模解空間的 LLM-Agent 框架

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-08-04
- 🕒 收錄時距發布：11 天
- 🔗 主要來源：https://arxiv.org/abs/2608.04341
- 📊 綜合評分（AI 判斷）：4.2 / 5
- 🧠 內容摘要：Mercari 研究團隊提出一個雙機制 LLM-Agent 框架：(1) 持續改進獎勵迴路——以保留測試集排行榜分數為獎勵信號，驅動單一 Agent 反覆優化提交方案；(2) 並行自主探索底層——支援多 Agent 全自主並行搜尋大規模解空間，無需人工介入。於產品目錄匹配任務實證：單 Agent 合格覆蓋率 47.8–57.4%，五 Agent 並行提升至 62.8–69.4%，顯著超越 33.3% 基線。論文獲接收於 ACM KDD'26 Workshop on SciSoc Agents & LLMs（2026 年 8 月、濟州島）。
- 📌 核心價值：首個將「保留測試集排行榜」形式化為 Agent 內在獎勵信號的框架，證明並行自主探索能發現質化不同的解決方案，為科學發現與工程優化任務提供可復現的自主搜尋基礎設施。
- 🌍 應用情境與實務影響：電商目錄匹配、藥物分子優化、晶片佈局搜尋等大規模離散優化問題，可直接套用此框架部署自主 Agent 群，無需人工設計獎勵函數或監督訓練資料。
- 🗂 知識庫連結：[[Papers/continuous-improvement-parallel-autonomous-exploration-llm-agent]]
## AI 應用與部署 / AI Applications & Deployment

### Lodestar：面向異構叢集的線上學習 LLM 推理路由器

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-05-31
- 🕒 收錄時距發布：76 天
- 🔗 主要來源：https://arxiv.org/abs/2606.00946
- 📊 綜合評分（AI 判斷）：4.3 / 5
- 🧠 內容摘要：針對大規模 LLM 推理部署中路由決策依賴靜態啟發式、難以適應異構硬體與動態負載的痛點，作者提出 Lodestar——首個線上學習式推理路由器。Lodestar 將路由建模為情境多臂老虎機問題，以請求特徵（前綴快取機會、排隊長度、GPU 利用率、KV cache 命中率等）為情境，即時更新路由策略，無需離線訓練資料。在包含多代 GPU（A100、H100、L40S）的異構叢集實測中，Lodestar 於約 5 分鐘線上學習後，平均 TTFT 降低 1.25–4.38×、P99 延遲降低 1.32–4.42×，顯著優於 Round-Robin、Least-Load、Prefix-Aware 等基線。
- 📌 核心價值：首個證明「線上學習路由」在生產級異構 LLM 叢集可行的系統，解決離線訓練覆蓋率不足與分布漂移問題，為 Kubernetes 原生推理閘道（IGW）與 llm-d 等編排層提供可直接整合的智慧路由模組。
- 🌍 應用情境與實務影響：雲端服務商與企業可直接將 Lodestar 整合至 vLLM/SGLang/TGI 叢集前端，無需修改模型或推理引擎即可獲得自適應路由收益；對多租戶、多模型混部場景價值更大。
- 🗂 知識庫連結：[[Papers/lodestar-online-learning-llm-inference-router]]
