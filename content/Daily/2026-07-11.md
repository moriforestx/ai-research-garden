# 2026-07-11 每日 AI 研究

> [!summary] 今日摘要
> 今日 AI 領域呈現三大趨勢：一、Foundation model 持續快速演進，Meta 發布 Muse 系列、Step-Audio 2 等多模態模型；二、長上下文 LLM 與 RAG 的結合成為研究熱點，提出訓練免費與訓練式的魯棒性方案；三、AI Agent 架構走向成熟，從 ReAct 到多代理協作、編碼代理、企業級工作流自動化均有完整綜述。Computer Vision 領域 YOLO 系列進化至 YOLO26/YOLOE 統一開放詞彙檢測分割，Audio 領域 Step-Audio 2 與 InstructAudio 達成統一語音音樂生成與理解。GitHub 熱門專案聚焦於本地 LLM 推理、Agent 框架、瀏覽器自動化工具。

## 今日重點

### AI 最新資訊
- **Meta 發布 Muse 系列：Muse Image、Muse Video、Muse Spark** (5★) — 統一圖像、視頻、3D 生成，展示向統一世界模型邁進。[Source](https://ai.meta.com/blog/introducing-muse-image-muse-video-msl/)
- **Segment Anything Model 3 (SAM 3) 發布** (4★) — 推進提示式分割，支援更多模態輸入，零樣本泛化能力增強。[Source](https://ai.meta.com/blog/segment-anything-model-3/)
- **Tribe V2：大腦預測基礎模型** (4★) — 從神經科學角度構建的預測式基礎模型，模擬大腦皮層預測機制。[Source](https://ai.meta.com/blog/tribe-v2-brain-predictive-foundation-model/)

### Computer Vision / 影像辨識 AI
- **Ultralytics YOLO 演進：YOLO26、YOLO11、YOLOv8、YOLOv5 綜述** (5★) — YOLO26 移除 DFL、原生 NMS-free 推理、ProgLoss、STAL 標籤分配、MuSGD 優化器；首個原生統一 5 大任務。[Source](https://arxiv.org/html/2510.09653v3)
- **YOLOE：Real-Time Seeing Anything (開放詞彙檢測分割)** (5★) — 統一文本/視覺/無提示三種開放詞彙機制；SAVPE 語義激活視覺提示編碼器；LVIS 上 3× 訓練成本降低、1.4× 推理加速。[Source](https://arxiv.org/html/2503.07465v1)
- **RF-DETR vs YOLOv12：果園環境下 Transformer vs CNN 對比** (3★) — RF-DETR mAP@50 0.8298；YOLOv12L mAP@50:95 0.6622；RF-DETR 單類別 <10 epochs 收斂。[Source](https://arxiv.org/html/2504.13099v1)

### LLM / NLP
- **Long-Context LLMs Meet RAG：長上下文 LLM 與 RAG 的魯棒性挑戰與解決方案** (5★) — 發現長上下文 LLM 隨檢索段落增加質量先升後降；提出三種方案：(1) 訓練免費：檢索重排序 (2) 隱式微調：針對難負樣本魯棒性 (3) 顯式微調：中間推理識別相關性。[Source](https://arxiv.org/html/2410.05983v1)
- **RAG in the Era of Long-Context LLMs (Medium 文章)** (4★) — 長上下文 (2M+ tokens) 擴展 RAG 設計空間而非取代；實驗設計選擇導致看似矛盾結論。[Source](https://medium.com/tr-labs-ml-engineering-blog/rag-in-the-era-of-long-context-llms-b8ecda2d5693)
- **U-NIAH：統一 RAG 與 LLM 長上下文評估基準** (4★) — 統一針對 RAG 和長上下文 LLM 的 Needle-in-Haystack 評估，分析錯誤模式。[Source](https://dl.acm.org/doi/10.1145/3786609)

### Audio / Speech
- **Step-Audio 2：端到端多模態大音頻語言模型** (5★) — 潛在音頻編碼器 + 推理導向 RL；端到端語音對話；ASR 多語言 SOTA；數百萬小時訓練；130B 參數規模；統一理解與生成。[Source](https://arxiv.org/html/2507.16632v1)
- **InstructAudio：自然語言指令統一語音與音樂生成** (4★) — 指令控制音色(性別/年齡)、超語言(情感/風格/口音)、音樂(流派/樂器/節奏/氛圍)；聯合/單擴散 Transformer。[Source](https://arxiv.org/pdf/2511.18487)
- **Voice Cloning: Comprehensive Survey (語音克隆綜述)** (4★) — 標準化術語、少樣本/零樣本/多語言 TTS、評估指標、數據集彙整。[Source](https://arxiv.org/html/2505.00579v1)
- **"Voice Cloning is Style Transfer"：語音克隆實為風格遷移** (4★) — 克隆聲音非忠實複製，系統性風格遷移；人類感知克隆聲音更權威、溫暖、可信；說話人特徵同質化。[Source](https://arxiv.org/html/2605.16578v2)
- **Marco-Voice：統一聲音克隆與情感控制 TTS** (3★) — 說話人-情感解耦對比學習、旋轉情感嵌入；CSEMOTIONS 數據集 (10h 中文、6 人、7 情感)。[Source](https://arxiv.org/html/2508.02038v1)

### AI Agents
- **AI Agent Systems: Architectures, Applications, and Evaluation (arXiv 綜述)** (5★) — 系統性綜述 Agent 架構三維度：(i) 審議推理 (CoT、自我反思、約束感知) (ii) 規劃控制 (反應式到分層多步) (iii) 工具調用環境交互；模塊化工具路由 (MRKL) 改善治理。[Source](https://arxiv.org/html/2601.01743v1)
- **AI Agents and Autonomous Systems: Architecture, Applications, and Evaluation (IJFMR 期刊)** (4★) — 結構化文獻回顧 2022-2025：AutoGen、ReAct、MetaGPT、LangChain、CrewAI、AutoGPT、Toolformer、Reflexion、Voyager、ChatDev、AgentBench 等框架/基準對比表。[Source](https://www.ijfmr.com/papers/2026/3/77786.pdf)
- **From LLM Reasoning to Autonomous AI Agents: A Comprehensive Review** (4★) — 涵蓋 ~60 基準、醫療/金融/科研/軟體工程應用；新基準：MedChain、LegalAgentBench。[Source](https://arxiv.org/abs/2504.19678)

### GitHub / Tools / Projects
- **Skyvern：自主網頁自動化 Agent** (5★) — 基於視覺+LLM 的瀏覽器自動化，無需腳本適應網站變化，支援複雜工作流。[Source](https://github.com/Skyvern-AI/skyvern)
- **LocalAI：免費開源 OpenAI API 替代品** (5★) — 本地運行 LLMs、音頻、圖像模型，提供 OpenAI 兼容 API；支援 llama.cpp、GGUF、ONNX。[Source](https://github.com/mudler/LocalAI)
- **Agent Lightning (Microsoft)：強化學習訓練 Agent** (4★) — 用 RL 優化 Agent 策略，超越提示工程，支援多輪工具使用優化。[Source](https://github.com/microsoft/agent-lightning)
- **DeepCode (HKUDS)：想法到生產代碼** (4★) — 端到端代碼生成 Agent，從需求到可部署代碼。[Source](https://github.com/HKUDS/DeepCode)
- **llama.cpp / goose / nano-vLLM 等高性能推理工具** (4★) — 本地推理生態成熟，部署選擇豐富。[Source](https://github.com/ggml-org/llama.cpp)
- **Langflow：低代碼 AI Agent/RAG 工作流平台** (4★) — 基於 LangChain 的視覺化工作流構建器，支援 Agent、RAG、多模型。[Source](https://blog.bytebytego.com/p/top-ai-github-repositories-in-2026)
- **Dify：生產級 Agentic 工作流平台** (4★) — 工作流構建器、內建 RAG、多模型供應商、監控、本地/雲部署。[Source](https://blog.bytebytego.com/p/top-ai-github-repositories-in-2026)
- **Awesome AI DevTools：AI 原生 IDE 與開發工具精選** (3★) — Cursor、Replit、Google Antigravity、Theia IDE、GitHub Copilot、Amazon Q Developer 等分類匯總。[Source](https://github.com/jamesmurdza/awesome-ai-devtools)
