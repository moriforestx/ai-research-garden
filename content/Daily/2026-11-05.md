- 📅 發布日期：2026-11-01
- 🕒 收錄時距發布：4 天
- 🔗 主要來源：https://arxiv.org/abs/2611.02160
- 📊 綜合評分（AI 判斷）：4.2 / 5
- 🧠 內容摘要：提出 Value Forcing 方法，利用流匹配估算回報分佈，在有限資料下實現準確的價值學習。核心洞見是在每個雜訊層級強制貝爾曼一致性，提取更豐富的學習訊號。
- 📌 核心價值：在離線強化學習的 26 個長時程任務中優於既有價值學習方法，資料有限時增益特別明顯。

## 電腦視覺 / Computer Vision

### SPOD: Recovering Suppressed Temporal Evidence in Video-LLMs via Single-Pass Orthogonal Decomposition

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-11-03
- 🕒 收錄時距發布：2 天
- 🔗 主要來源：https://arxiv.org/abs/2611.04728
- 📊 綜合評分（AI 判斷）：4.3 / 5
- 🧠 內容摘要：提出 SPOD（單次正交分解）框架，無需重新訓練即可在單次前向傳播中恢復 Video-LLM 中被抑制的時間證據。包含幀獨特性分析 (FDA) 與時間增量子空間 (TDS) 兩組件，分解隱藏狀態為時間、先驗與殘差分量並獨立重新縮放。
- 📌 核心價值：在 VidHalluc、EventHallusion、VideoMMMU 基準測試上超越強基線，保持近乎原生的推理效率，證明改善時間推理不一定需要額外監督。
- 🌍 應用情境與實務影響：解決 Video-LLM 在場景轉換理解、事件排序等時間敏感推理任務中的幻覺問題，免訓練、高效率，易於部署到現有模型。
- 🗂 知識庫連結：[[Papers/spod-recovering-suppressed-temporal-evidence]]
## 大型語言模型與自然語言處理 / LLM & NLP

### GatedV: Self-Gated Values for Transformer Language Models

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-11-01
- 🕒 收錄時距發布：4 天
- 🔗 主要來源：https://arxiv.org/abs/2611.02145
- 📊 綜合評分（AI 判斷）：4.1 / 5
- 🧠 內容摘要：提出 GatedV，一種簡單的注意力變體，僅在聚合前對 Value 矩陣應用 SiLU 激活函數，不引入額外可訓練參數。在匹配參數量、配對初始化、相等訓練 token 預算下評估。
- 📌 核心價值：2.33M 參數模型將平均 held-out perplexity 從 59.1 降至 57.9 (2.0%)；26.16M 參數模型從 20.2 降至 19.7 (2.4%)，所有配對種子均改善。
- 🌍 應用情境與實務影響：證明僅針對 Value 的自我閘控即可在不增加參數量、不重設計注意力加權機制的前提下提升語言建模性能，易於整合進現有 Transformer 架構。
- 🗂 知識庫連結：[[Papers/gatedv-self-gated-values-transformer]]
## 音訊與語音 / Audio & Speech

### Learning Timeline-Preserving Speech-to-Speech Translation

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-10-31
- 🕒 收錄時距發布：5 天
- 🔗 主要來源：https://arxiv.org/abs/2611.00690
- 📊 綜合評分（AI 判斷）：4.4 / 5
- 🧠 內容摘要：提出 TransDubber，一個端到端自回歸系統，學習保留源端點與關鍵內部停頓的時間結構，無需推理時幀級時序控制或事後時間校正。構建 642K 對精確時長匹配的英中語音對，結合漸進式監督課程與驗證器引導強化學習。
- 📌 核心價值：在 4,353 條測試語料上，Dur@2% 從 25.6% 提升至 61.5%，暫停對齊 F1 從 0.118 提升至 0.550，同時保持具競爭力的翻譯品質。
- 🌍 應用情境與實務影響：解決配音等時間敏感應用中語音與停頓必須對應發生的問題，提供大規模時間對齊語音語料與訓練框架，推動時間軸保留型 S2ST 研究。
- 🗂 知識庫連結：[[Papers/learning-timeline-preserving-speech-to-speech-translation]]
## AI 代理人 / AI Agents

### Decentralized Multi-Agent Coordination and Communication in Shared Codebases

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-10-30
- 🕒 收錄時距發布：6 天
- 🔗 主要來源：https://arxiv.org/abs/2611.00314
- 📊 綜合評分（AI 判斷）：4.3 / 5
- 🧠 內容摘要：提出 ParallACT 基準測試，研究無協調器的多智能體程式設計任務。包含互補型與矛盾型任務：互補任務需共享介面才能有效合併；矛盾任務需編輯相同程式碼但方式不相容。比較單智能體預言機與多智能體設定（執行順序、可見度、對方感知、通訊管道）。
- 📌 核心價值：預言機解決大多數任務，但並行智能體顯著較差，尤其矛盾任務（如 Claude Code + Opus 4.8 從 62% 降至 16%）。僅告知對方存在無顯著幫助，通訊管道僅回收小部分效能並增加 token 成本。
- 🌍 應用情境與實務影響：隔離出多智能體獨立開發共享代碼庫的核心協調難題，提供受控測試平台評估協調策略成本效益，隨著多智能體程式設計成常態將愈發重要。
- 🗂 知識庫連結：[[Papers/decentralized-multi-agent-coordination-shared-codebases]]
## AI 應用與部署 / AI Applications & Deployment

### Do Coding Agents Catch Their Own Bugs? (They Don't.)

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-10-31
- 🕒 收錄時距發布：5 天
- 🔗 主要來源：https://arxiv.org/abs/2611.01181
- 📊 綜合評分（AI 判斷）：4.2 / 5
- 🧠 內容摘要：提出 Foresight-SWE 基準測試，衡量程式設計智能體是否能預見並解決軟體工程任務中未明確規定的潛在問題（如前瞻性考慮漏洞或 Bug）。包含 212 樣本，橫跨 4 種語言、35 個熱門開源倉庫，每樣本含兩個 PR（第二個修正第一個引入的缺陷）。定義「預見解決率」(FRR) 為同時完成原任務並避免後續 PR 識別缺陷的比例。
- 📌 核心價值：評估 11 個大型語言模型，FRR 僅 6.13% 到 24.53%，顯示模型多數無法解決首個 PR 變更引入的問題。揭示編碼場景下模型訓練與對齊的缺口，以及程式碼審查工具需改進以實現更安全編碼。
- 🌍 應用情境與實務影響：將評估導向前瞻性缺陷預防，對 AI 輔助程式碼生成的生產部署可靠性至關重要。提供基準推動更安全的編碼智能體開發。
- 🗂 知識庫連結：[[Papers/do-coding-agents-catch-their-own-bugs]]
