## 電腦視覺 / Computer Vision

### LongVT：透過原生工具呼叫實現「長影片思考」的端到端代理框架 (CVPR 2026)

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-06-01
- 🕒 收錄時距發布：171 天
- 🔗 主要來源：https://openaccess.thecvf.com/content/CVPR2026/papers/Yang_LongVT_Incentivizing_Thinking_with_Long_Videos_via_Native_Tool_Calling_CVPR_2026_paper.pdf
- 📊 綜合評分（AI 判斷）：4.3 / 5
- 🧠 內容摘要：LongVT 針對大型多模態模型 (LMM) 處理長影片時產生幻覺、難以定位稀疏時序證據的問題，提出首個端到端代理框架，透過交錯多模態工具鏈思維 (iMCoTT) 實現「長影片思考」。模型利用內建的時序定位能力作為原生 `crop_video` 工具，先全域預覽再按需擷取細粒度片段，反覆推理直到答案落在視覺證據上。作者構建 VideoSIAH 基準與資料套件，三階段訓練 (SFT → RL → 微調) 後，LongVT 在長影片問答、時序定位等任務顯著優於基線，並釋出開源代碼與模型。
- 📌 核心價值：首創將 LMM 內建定位能力轉化為可微工具鏈，讓模型像人類「略讀→細讀」般處理時長數小時影片，開啟代理式長影片推理新範式。
- 🌍 應用情境與實務影響：適用於長會議紀錄分析、監控影片檢索、影片問答系統等需跨越時序推理的場景；開源模型與 VideoSIAH 基準可直接用於後續研究與產品化落地。
- 🗂 知識庫連結：[[Papers/longvt-cvpr-2026]]

- 🗂 內容類型：工具與專案 / Tools & Projects
- 📅 發布日期：2026-10-29
- 🕒 收錄時距發布：21 天
- 🔗 主要來源：https://www.langchain.com/blog/managed-deep-agents-browser-use-and-asynchronous-subagents
- 📊 綜合評分（AI 判斷）：4.3 / 5
- 🧠 內容摘要：LangChain 於 2026-10-29 釋出 Managed Deep Agents v0.10 (公測自 8/7 起)，新增兩大核心能力：(1) 瀏覽器操作 —— 內建四種瀏覽器工具，支援無 API 網站自動化，登入時可將視窗移交人工處理，密碼不進模型上下文；(2) 非同步子代理 —— 子代理可在背景執行緒長時間運行，不阻塞主對話，提供啟動、查詢、更新、取消工具與完成通知機制。同步釋出執行緒來源追蹤 (Slack 回覆歸屬) 與停止鈕取消執行。Python/JS SDK 僅需在 subagent 定義加 `async: True` 即可啟用。
- 📌 核心價值：將「瀏覽器自動化」與「非同步任務編排」納入代理運行時標準庫，解決長任務阻塞對話、憑證隔離等生產痛點，推動代理從示範走向可交付服務。
- 🌍 應用情境與實務影響：開發者可直接部署會預訂機票、填表單、後台跑報表的代理，無需自建瀏覽器基礎設施；非同步模式讓使用者體驗從「等待回應」轉為「持續對話、稍後收結果」。
