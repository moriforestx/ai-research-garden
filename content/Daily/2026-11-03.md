## 電腦視覺 / Computer Vision

### SAM 3D: 3Dfy Anything in Images

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-06-02
- 🕒 收錄時距發布：154 天
- 🔗 主要來源：https://ai.meta.com/research/publications/sam-3d-3dfy-anything-in-images
- 📊 綜合評分（AI 判斷）：4.6 / 5
- 🧠 內容摘要：Meta Superintelligence Labs 發表 SAM 3D，從單張圖片重建物體完整 3D 幾何、紋理與佈局。透過人機協同標註管線（Human- and Model-in-the-Loop）大規模生成視覺定錨的 3D 重建資料，結合 Direct Preference Optimization (DPO) 與 Render-and-Paste 方法，在真實世界場景（含遮擋與雜亂）顯著超越既有 3D 生成模型。獲 CVPR 2026 Best Paper Honorable Mention。
- 📌 核心價值：將 SAM 分割能力延伸至 3D 重建，以可擴展資料引擎解決 3D 標註瓶頸，為單圖 3D 重建建立新基準。
- 🌍 應用情境與實務影響：適用於 AR/VR 內容生成、機器人感知、電商 3D 資產自動化、數位孿生等需從單張照片快速獲得高品質 3D 資產的場景。代碼與模型已開源，可直接整合至下游應用。
- 🗂 知識庫連結：[[Papers/sam-3d-3dfy-anything-in-images]]

### NVIDIA Nemotron 3.5 Lightning 與 NeMo Switchyard：針對長期代理 AI 工作負載的最高效開放模型

- 🗂 內容類型：技術動態與落地 / Technical Developments & Applications
- 📅 發布日期：2026-08-11
- 🕒 收錄時距發布：84 天
- 🔗 主要來源：https://blogs.nvidia.com/blog/nemotron-lightning-switchyard-rtx-dgx
- 📊 綜合評分（AI 判斷）：4.4 / 5
- 🧠 內容摘要：NVIDIA 正式發布 Nemotron 3.5 Lightning，採用混合 Mamba-2 + Attention + MoE 架構，30B 總參數、3B 活躍參數、支援 1M token 上下文，專為長期運行的代理式 AI 工作負載優化。同步釋出 NeMo Switchyard 路由工具，讓開發者在邊緣裝置、PC、工作站、資料中心與雲端間靈活調度模型。模型採 OpenMDW-1.1 許可（允許商用），提供 BF16 與 NVFP4 量化檢查點，單張消費級/工作站級 GPU 即可運行。
- 📌 核心價值：將百億級混合架構模型壓縮至單 GPU 可跑等級，並配套路由工具，大幅降低部署自主代理的門檻與成本。
- 🌍 應用情境與實務影響：適用於本地端代理部署、長對話 RAG、程式碼生成代理、邊緣推理等場景。開發者可透過 Ollama、Hugging Face、AWS SageMaker JumpStart、NVIDIA NIM 等多管道取得權重與推理服務。
- 🗂 知識庫連結：[[TechnicalDevelopments/nemotron-3.5-lightning-nemo-switchyard]]
## 音訊與語音 / Audio & Speech

### Deepgram Flux TTS：面向即時語音代理的對話原生文字轉語音模型

- 🗂 內容類型：技術動態與落地 / Technical Developments & Applications
- 📅 發布日期：2026-08-12
- 🕒 收錄時距發布：83 天
- 🔗 主要來源：https://deepgram.com/learn/introducing-flux-tts-conversation-native-text-to-speech-for-real-time-voice-agents
- 📊 綜合評分（AI 判斷）：4.3 / 5
- 🧠 內容摘要：Deepgram 正式發布 Flux TTS，首款「對話原生」TTS 模型，能讀取完整對話脈絡而非單行文本，原生支援打斷處理、上下文保持、自然語調與情感表達，無需 SSML 或風格標籤。端到端延遲極低，配合既有 Flux STT（含多語言與自動語言偵測）與 Voice Agent API，提供語音辨識、代理推理、語音生成一站式編排。8/12 起正式上線，9/12 前免費額度每月 45 併發串流（EU/AU 5 串流），正式定價 $0.045/千字元。
- 📌 核心價值：將 TTS 從「逐行朗讀」提升為「對話感知」，解決語音代理在真實對話中斷、插話、情感轉換等痛點，大幅簡化語音代理開發堆疊。
- 🌍 應用情境與實務影響：適用於客服語音機器人、即時翻譯耳機、語音助理、電話銷售代理等需低延遲、高自然度、可被打斷的即時語音互動場景。開發者可透過單一 API 串接 STT→LLM→TTS 全鏈路。
- 🗂 知識庫連結：[[TechnicalDevelopments/deepgram-flux-tts-conversation-native]]

- 🗂 內容類型：研究成果 / Research
- 📅 發布日期：2026-08-24
- 🕒 收錄時距發布：71 天
- 🔗 主要來源：https://arxiv.org/abs/2608.23642
- 📊 綜合評分（AI 判斷）：4.4 / 5
- 🧠 內容摘要：Hugging Face 與 Data & Society 研究者 Margaret Mitchell、Avijit Ghosh、Samir Passi 發表立場論文，指出當前 AI 代理系統設計阻礙有效人類監督，且長期使用自動化系統會降低監督所需的認知能力。論文主張「完全自主 AI 代理不應被開發」，並呼籲社群將人類監督設計置於代理開發核心。獲選為 NeurIPS 2026 海報論文。

## AI 應用與部署 / AI Applications & Deployment

### Amazon Bedrock AgentCore Runtime Instances：面向生產級 AI 代理的持久託管 EC2 基礎設施正式上線

- 🗂 內容類型：技術動態與落地 / Technical Developments & Applications
- 📅 發布日期：2026-08-10
- 🕒 收錄時距發布：85 天
- 🔗 主要來源：https://aws.amazon.com/blogs/aws/runtime-instances-persistent-compute-for-production-ai-agents-on-amazon-bedrock-agentcore
- 📊 綜合評分（AI 判斷）：4.3 / 5
- 🧠 內容摘要：AWS 正式發布 Amazon Bedrock AgentCore Runtime Instances，為生產級 AI 代理提供持久、託管的 EC2 基礎設施。相較於預設的微型 VM（會話 ≤8 小時、快速啟動），Runtime Instances 支援長達 14 天的長期會話、GPU 加速、多代理共置協作、會話停止/重啟省成本、容器化部署，並可選用完整 EC2 執行個體類型（GPU、記憶體優化、運算優化）。同步上線 AWS Agent Registry（自動偵測、客戶管理金鑰加密）與 DynamoDB 原生向量搜尋。已在 9 個區域 GA。
- 📌 核心價值：將代理運行時從「暫時性無狀態」提升為「持久有狀態、可攜帶專屬依賴與硬體」，解決長時間運行、重運算、多代理協作的生產部署缺口。
- 🌍 應用情境與實務影響：適用於程式碼編譯/安全掃描/資料管線等長時間運算代理、需共享記憶體的多代理編排、GPU 密集型推理工作負載。團隊可透過 Capacity Provider 宣告所需 EC2 型別，透過相同 AgentCore API 無縫切換微型 VM 與 Instances。
- 🗂 知識庫連結：[[TechnicalDevelopments/bedrock-agentcore-runtime-instances-ga]]
