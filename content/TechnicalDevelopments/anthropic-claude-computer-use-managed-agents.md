# Claude Computer Use 進入 Team/Enterprise 正式測試、Managed Agents 自託管上線

## 基本資訊

- 發布日期：2026-11-20
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://platform.claude.com/docs/en/release-notes/overview

## 概要

Anthropic 於 2026-11-20 依官方 release notes 將 Computer Use（電腦操作）功能以 beta 形式推出至 Claude Team 與 Enterprise 方案，逐步向組織開放。功能預設關閉，需 Owner/Primary Owner 在組織設定 → Capabilities 啟用；管理員可封鎖特定應用程式或設定允許清單。同期（11/12）另推出自託管 Claude Managed Agents，企業可在自有基礎設施完整運行 Managed Agents 服務（含沙箱、會話、歷史），模型請求預設發送至 Anthropic。11/17 另新增 Claude Desktop 釋出通道切換（Stable/Latest）。標誌 AI 代理人從研究預覽邁向企業級生產部署。

## 核心價值

首個面向企業團隊的桌面級 Computer Use 正式測試版，配合自託管 Managed Agents，提供合規、可稽核的代理人部署路徑。

## 應用情境與實務影響

企業可在受控環境讓 Claude 自動化重複性桌面任務（表單填寫、資料擷取、跨應用協作），同時保留人工監督與應用隔離；自託管選項滿足資料主權與合規需求。

## 補充細節

Computer Use beta 於 2026-11-20 依 Anthropic release notes 釋出；Managed Agents 自託管於 2026-11-12 上線；Desktop 釋出通道切換於 2026-11-17 新增。來源：platform.claude.com/docs/en/release-notes/overview、Anthropic Claude release notes 2026-11-20。
