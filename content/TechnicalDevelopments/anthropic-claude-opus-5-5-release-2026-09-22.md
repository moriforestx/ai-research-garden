# Anthropic 發布 Claude Opus 5.5：性能達 Fable 5.1 級、成本降 40%

## 基本資訊

- 發布日期：2026-09-22
- 研究主題：大型語言模型與自然語言處理 / LLM & NLP
- 主要來源：https://www.anthropic.com/claude-opus-5-5

## 概要

Anthropic 於 2026 年 9 月 22 日正式推出 Claude Opus 5.5，作為 Claude 5.5 系列首款模型。官方宣稱其在多數任務上達到 Claude Fable 5.1 水準，但成本較 Opus 5 降低約 40%（輸入 $4/M、輸出 $20/M token）。模型採 100 萬 token 上下文窗、12.8 萬 token 最大輸出、預設開啟思考模式且不可關閉，並導入「保留思考」防蒸餾機制（針對 8/31 後建立的 API 帳號）。同步上線 Amazon Bedrock、AWS/GCP/Azure 平台。

## 核心價值

首個強制啟用思考模式且內建防蒸餾保護的 Opus 級模型，以 40% 更低成本提供近 Fable 級推理能力，重新定義高性價比長程代理編程與知識工作的基準。

## 應用情境與實務影響

降低企業級代理工作流與長上下文編程的 API 成本門檻；強制思考模式提升可靠性但需調適既有提示工程；防蒸餾機制回應 EU AI Act 合規需求；零資料保留選項滿足嚴格合規場景。

## 補充細節

Claude Sonnet 5.5 於 9/28 發布、Haiku 5.5 於 10/7 發布，構成完整 5.5 系列。模型 ID 為 claude-opus-5-5（無日期後綴）。Opus 4.8 快速模式於 10/30 棄用、建議遷移至 Opus 5.5。
