# OpenAI DevDay 2026：發布 GPT-6.1 Sol、Dots AI 代理人與 ChatGPT Space 協作平台

## 基本資訊

- 發布日期：2026-09-29
- 研究主題：AI 綜合動態 / General AI Updates
- 主要來源：https://www.unite.ai/openai-unveils-gpt-6-1-sol-at-devday-with-new-codex-and-chatgpt-tools

## 概要

OpenAI 於 2026 年 9 月 29 日舉行年度 DevDay，發布超過 20 項重大更新。核心亮點包括：GPT-6.1 Sol 模型（編程、電腦使用、專業工作與事實準確度大幅提升，API 價格為每百萬輸入 token $2、輸出 $10）、Dots 持續型 AI 代理人（由 GPT-6 Astra 驅動，具備雲端電腦與連接應用程式能力，面向 Pro/Business Premium/企業方案推出）、ChatGPT Space 共享工作區（支援頁面、協作簡報與團隊合作）。另有 Codex 雲端環境、語音控制、代碼審查、Agents API 電腦使用、Decisions API、Pro 500 方案與 Ultrafast 速度選項等開發者工具與訂閱方案更新。

## 核心價值

確立了下一代 AI 代理人（Dots）與高性能編程模型（GPT-6.1 Sol）的商業化可用性，推動 AI 從聊天介面走向持續型、可執行任務的代理人範式。

## 應用情境與實務影響

開發者可立即透過 API 使用 gpt-6.1-sol 進行高品質編程與電腦使用任務；企業用戶獲得首個具備雲端電腦與應用連接能力的持續型代理人產品（Dots），可自動化跨應用工作流；ChatGPT Space 為團隊協作提供原生 AI 融合工作區。

## 補充細節

DevDay 2026 於美國舊金山舉行，Sam Altman 主持發布。GPT-6.1 Sol 於發布即日向 Plus、Pro、Business、Enterprise、Edu 方案用戶在 ChatGPT Work、Codex 及 API 開放。Dots 同步向 Pro、Business Premium、企業方案推出。OpenAI 另宣布 Decisions API 進入有限預覽、Agents API 新增電腦使用能力、Codex 引入雲端環境與語音控制、推出 Pro 500 方案與 Ultrafast 生成速度選項。
