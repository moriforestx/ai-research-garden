# Announcing a renaissance in computer vision AI with Microsoft's Florence foundation model

## 基本資訊

- 發布日期：2026-10-14
- 研究主題：電腦視覺 / Computer Vision
- 主要來源：https://azure.microsoft.com/en-us/blog/announcing-a-renaissance-in-computer-vision-ai-with-microsofts-florence-foundation-model

## 概要

Microsoft 發布 Florence 基礎模型公開預覽，整合至 Azure Cognitive Service for Vision。Florence 以數十億文本-圖像對訓練，支援自動圖像標題、密集標題、智能裁剪、分類、背景移除、自然語言圖像搜尋等功能，達到人類水平的標題生成效能。新版 Image Analysis 4.0 SDK (C#、C++、Python) 同步釋出，提供生產級電腦視覺服務。

## 核心價值

將大規模多模態基礎模型 Florence 直接整合至雲端生產服務，降低企業採用最先進電腦視覺能力的門檻，提供即用型 API 而非僅發布模型權重。

## 應用情境與實務影響

開發者可透過 Azure Vision Studio 立即試用 Florence 驅動的密集標題、視頻摘要、幀定位等功能；Reddit、H&R Block、Uber 等已採用於無障礙標題生成、文件處理、司機身份驗證等實務場景。SDK 支援 C#、C++、Python，便於整合至現有應用。

## 補充細節

Florence 為多模態基礎模型，支援圖像、視頻與語言聯合理解。Image Analysis 4.0 提供 captioning、dense captioning、smart crops、tags、objects、background removal、visual search 等開箱即用能力。Microsoft Ignite 2026 (11/17-20) 將進一步展示相關創新。Azure Maia 晶片架構同步優化推理效能。
