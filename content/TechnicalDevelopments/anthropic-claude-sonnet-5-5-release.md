# Anthropic 發布 Claude Sonnet 5.5：程式碼能力大幅提升、速度提升 30%+、成本降低 30%

## 基本資訊

- 發布日期：2026-09-28
- 研究主題：大型語言模型與自然語言處理 / LLM & NLP
- 主要來源：https://www.anthropic.com/claude-sonnet-5-5

## 概要

Anthropic 官方發布 Claude Sonnet 5.5，為 Claude 5.5 系列第二款模型。相比 Sonnet 5，程式碼能力大幅增強（Terminal-Bench 4.0 從 10.3% 升至 70.6%），推理速度提升 30% 以上，成本降低高達 30%。首個在無輔助下通過《寶可夢 紅》純螢幕截圖遊玩測試的 Sonnet 模型。同系列另包含 Opus 5.5（9/22 發布，代理編程領先、較 Opus 5 降本 40%）與 Haiku 5.5（10/7 發布，小型高吞吐模型）。所有模型支援 1M 上下文視窗與保護性思維防蒸餾機制。

## 核心價值

Sonnet 5.5 以中型模型達到接近 Opus 級的代理編程效能，大幅降低開發者採用高階推理模型的門檻；30% 速度與成本雙重優化改變生產環境部署經濟性。

## 應用情境與實務影響

開發者可用更低成本獲得頂級代理編程能力；企業可大規模部署長程推理工作負載；1M 上下文支援大型代碼庫整體推理；保護性思維機制提升 API 安全性。

## 補充細節

Terminal-Bench 4.0：Sonnet 5.5 70.6% vs Sonnet 5 10.3%。FrontierCode 1.1：46.2% (Max) / 52.1% (Xhigh)。GDPval-AA：1844 分（僅比 Opus 5.5 低 2 分）。CursorBench 4.0：55.5%。發布日期 2026-09-28，系統卡同步發布。系列時間軸：Opus 5.5 (9/22)、Sonnet 5.5 (9/28)、Haiku 5.5 (10/7)。
