# Meta FAIR 釋出 SAM 2.1 與八項 AI 研究成果

## 基本資訊

- 發布日期：2026-10-15
- 研究主題：電腦視覺 / Computer Vision
- 主要來源：https://ai.meta.com/blog/fair-news-segment-anything-2-1-meta-spirit-lm-layer-skip-salsa-lingua

## 概要

Meta FAIR 於 2026-10-15 發布八項開放研究成果，核心為 Meta Segment Anything Model 2.1 (SAM 2.1) 更新檢查點，針對視覺相似物件、小物件與遮擋處理顯著提升；同步釋出 SAM 2 Developer Suite 含微調訓練碼與網頁示範前後端代碼。其他成果含 Spirit LM（語音文本整合）、LayerSkip（LLM 推理優化）、SALSA（後量子密碼基準）、Lingua（大規模訓練框架）等。

## 核心價值

SAM 2.1 為統一影像/視訊分割模型的重要迭代，開放權重與完整開發套件大幅降低部署門檻，推動開放視覺基礎模型生態。

## 應用情境與實務影響

開發者可直接下載改進後的 SAM 2.1 權重並使用 Developer Suite 進行微調、部署與整合，適用於機器人視覺、醫療影像分割、視訊編輯與工業檢測等場景。

## 補充細節

SAM 2.1 採 Apache 2.0 授權。發布包含改進的物件追蹤、相似物件分離與遮擋處理。Developer Suite 含訓練碼、推理管線與網頁示範完整原始碼。同場發布的 Spirit LM 為首個開放語音文本統一模型。
