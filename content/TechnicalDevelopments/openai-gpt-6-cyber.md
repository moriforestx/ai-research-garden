# GPT‑6 Cyber：OpenAI 推出網安專用模型

## 基本資訊

- 發布日期：2026-11-05
- 研究主題：AI 綜合動態 / General AI Updates
- 主要來源：https://deploymentsafety.openai.com/gpt-6-cyber

## 概要

OpenAI 於 2026-11-05 正式發布 GPT‑6 Cyber，為 GPT‑6 Astra 的網安專用變體，專為授權安全工作設計，包含漏洞發現、漏洞利用開發與 Web 滲透測試。模型經專門後訓練以強化網安能力並降低拒答率，部署時採 Daybreak Red 存取控制、身分驗證、SSO、MFA 與 IP 允許名單等嚴格防護。依 Preparedness Framework 評級為 Critical (Cybersecurity)。官方系統卡詳述能力評估、防護機制與部署安全準則。

## 核心價值

首個獲官方認證可用於授權滲透測試與漏洞利用開發的前沿模型，並內建對齊監控機制確保行為在授權範圍內。

## 應用情境與實務影響

安全研究者與紅隊可透過 API 與 Codex 在授權範圍內使用前沿模型進行漏洞挖掘與修補驗證，推動 AI 輔助網安作業標準化。

## 補充細節

模型具備 1.05M token 上下文視窗、128K 最大輸出。在 ExploitGym 測試達 48.45% 成功率、SEC-Bench Pro 87.02%、SRE-Bench 92.84%。同步發布系統卡於 deploymentsafety.openai.com/gpt-6-cyber。
