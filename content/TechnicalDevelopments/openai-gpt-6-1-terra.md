# OpenAI 發布 GPT-6.1 Terra：大幅降低成本、提升電腦操作能力

## 基本資訊

- 發布日期：2026-10-26
- 研究主題：AI 綜合動態 / General AI Updates
- 主要來源：https://openai.com/index/introducing-gpt-6-1-terra

## 概要

OpenAI 於 2026 年 10 月 26 日正式發布 GPT-6.1 Terra，這是 GPT-6 系列中主打高性價比與電腦操作能力的模型。標準 API 定價為每百萬輸入 token 1 美元、每百萬輸出 token 5 美元，較 GPT-5.6 Terra 降低 50%。GPT-6.1 Terra 在 Agents' Last Exam 測試中大幅超越 GPT-5.6 Terra，且以十分之一價格達到 GPT-6 Astra 同等水準，任務完成速度更快 3 倍以上。已向 Plus、Pro、Enterprise、Edu 用戶在 ChatGPT Work 和 Codex 中開放，開發者可透過 API 以 gpt-6.1-terra 存取。

## 核心價值

以大幅降低的成本提供頂級電腦操作與視覺推理能力，讓高頻率自動化任務（如發票處理、資料輸入）在經濟上可行。

## 應用情境與實務影響

開發者可用更低成本部署大規模電腦操作代理；企業用戶在 ChatGPT Work 中獲得更高效的視覺推理與跨應用操作模型。

## 補充細節

模型支援瀏覽器操作、桌面應用操作、圖像理解與精確的螢幕推理。對齊改進使其更傾向於揭露限制並抵禦提示注入。系統卡片提供詳細評測數據。
