# Microsoft Agent Framework Harness 與 Foundry Hosted Agents 達 GA，代理人進入生產級運行期

## 基本資訊

- 發布日期：2026-08-03
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://devblogs.microsoft.com/foundry/agent-service-build2026

## 概要

Microsoft 於 2026 年 8 月 3 日宣布 Agent Framework Harness 與 Foundry Hosted Agents 正式達到一般可用性。Agent Framework 1.0 於 4 月釋出穩定 SDK；Build 2026 (6/2-3) 推出 Harness、GitHub Copilot SDK 與 Claude Agent SDK 連接器、多代理編排模式；8 月 Harness 與託管代理服務同步 GA。Harness 提供技能、記憶體、中介軟體、檔案系統工具、深度研究代理；Hosted Agents 提供沙箱隔離、長時程執行、常式自動化、部署至 Teams/Copilot、私有技能目錄、帶狀態恢復、可導向代理回合等企業級能力。

## 核心價值

標誌 AI 代理人框架從開發庫跨越至受支援的生產級運行環境，含託管沙箱、可觀測性、治理與多框架互通。

## 應用情境與實務影響

企業可在不綁定單一框架前提下，將 LangGraph、Microsoft Agent Framework、GitHub Copilot SDK、Claude Agent SDK 等建構的代理部署至統一受控運行期，支援長時程、人工介入、成本優化與合規需求。

## 補充細節

Build 2026 同步釋出：Magentic-One 多代理模式穩定版、Toolboxes 技能支援、程序記憶體、Voice Live 整合。Foundry Agent Service 支援 Responses API、MCP、A2A 協定。InfoQ 報導確認 8/3 GA。
