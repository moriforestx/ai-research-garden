# Google unveils Gemini Enterprise Agent Platform at Cloud Next 2026 with unified agent building and deployment capabilities

## 基本資訊

- 發布日期：2026-07-15
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://cloud.google.com/resources/content/ai-agent-trends-2026

## 概要

Google 在 2026 年 7 月 15 日的 Cloud Next 2026 大會上發布 Gemini Enterprise Agent Platform，將 Vertex AI 重新定位為企業級 AI Agent 一體化平台。該平台整合了代碼優先的 Agent Development Kit (ADK)、低代理視覺建構器 (Agent Studio)、200+ 基礎模型（含 Gemini 和 Claude）、受管理執行時環境 (Agent Engine)、持久記憶體與企業治理功能，提供 end-to-end 的 AI Agent 建置、部署與管理解決方案。

## 核心價值

企業級 AI Agent 平台整合開發、部署、治理與執行於一體，降低建置門檻並提升生產力。

## 應用情境與實務影響

企業可透過自然語言或程式碼快速建置跨部門的 AI Agent 自動化工作流程，涵蓋客戶服務、資料分析、流程自動化及知識管理等場景，同時獲得完整的監控、版本控制與安全合規功能。

## 補充細節

平台包含五大核心組件：1) Agent Studio - 无代码可视化构建器，让业务用户通过自然语言描述自动化需求（如 "每週五提醒我更新追蹤器"）；2) Agent Development Kit (ADK) v1.0 - 支持四种语言的代码优先开发套件；3) Model Garden - 提供超过200个基础模型，包括Google自有模型和第三方模型如Claude；4) Agent Engine - 受管理的运行时环境，支持弹性伸缩和生产级别的服务等级协议；5) 企业治理套件 - 包含访问控制、审计日志、数据隐私保护及模型风险管理工具。平台还特别提及了Project Mariner（网页浏览智能体）和Workspace Studio（Google Workspace无代码自动化构建器）。
