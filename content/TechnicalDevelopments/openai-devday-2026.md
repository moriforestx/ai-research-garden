# OpenAI DevDay 2026：GPT-6.1 Sol、Codex 雲端環境、Agents API 電腦使用與持久代理人 Dots

## 基本資訊

- 發布日期：2026-09-29
- 研究主題：AI 綜合動態 / General AI Updates
- 主要來源：https://openai.com/index/devday-2026-recap

## 概要

OpenAI 於 2026 年 9 月 29 日舉辦 DevDay 開發者大會，發布超過 20 項重大更新。核心發布包括：GPT-6.1 Sol 模型（針對專業工作、電腦使用與代理式編碼優化）、Codex 雲端執行環境（支援遠端任務、語音輸入、/agents 介面與程式碼審查工作流）、Agents API 新增電腦使用能力、Decisions API、Ultrafast 專屬高速層（Codex 最高 300 tokens/秒）、Private Intelligence 隱私增強預覽，以及持久代理人 Dots（可跨會話保持工作脈絡）。OpenAI 另宣布 ChatGPT 週活用戶達 12 億。

## 核心價值

確立「持久 AI 工作者」為新範式：模型能力（GPT-6.1 Sol）、執行環境、代理介面與協作介面四位一體，將代理式 AI 從實驗階段推向生產級開發者基礎設施。

## 應用情境與實務影響

開發者可直接在雲端啟動 Codex 環境、委派多任務給 /agents、使用 Decisions API 處理結構化決策、利用 Ultrafast 加速推理；企業可透過 Private Intelligence 控管資料。對 AI 代理人、編碼助手與企業級部署均具參考價值。

## 補充細節

主要發布項目：(1) GPT-6.1 Sol：繼 GPT-6 Sol 釋出一週後推出，強化專業任務、電腦操作與代理式編碼。(2) Codex Cloud：雲端 IDE，支援遠端啟動、語音輸入、/agents 多任務委派、GitHub/GitLab PR 程式碼審查、Codex Security Cloud 掃描修復。(3) Agents API 電腦使用：代理人可操作虛擬機瀏覽、點擊、輸入。(4) Decisions API：結構化決策輸出。(5) Ultrafast：GPT-6 Astra 最高 8×、GPT-6.1 Sol 最高 6× 速度。(6) Private Intelligence：資料隔離與合規預覽。(7) Dots：持久代理人，跨會話保持專案脈絡。(8) ChatGPT Space/Pages、Plugins、@ChatGPT 整合 Slack/Teams。
