# World Model Science: Self-Organized Criticality, Weak Chaos, and Metastable Belief Dynamics in Long-Horizon LLM Agents

## 基本資訊

- 發布日期：2026-09-16
- 研究主題：大型語言模型與自然語言處理 / LLM & NLP
- 主要來源：https://arxiv.org/html/2609.17419v1

## 概要

提出 World Model Science 框架，透過自組織臨界性、弱混沌與穩定態信念動力學三種動力學視角研究長距離 LLM 代理人軌跡。透過 22 項橫跨解謎題、工具使用、具身任務、多跳檢索、通用助理推理與生命遊戲的實證研究，發現局部有效行動可在全域狀態忠實度失效後持續存在，壓力可導致 abrupt 崩解，錯誤序列具長時程記憶，且更長時間尺度支援更大規模錯誤 avalanches。

## 核心價值

首次將複雜系統科學概念應用於 LLM 代理人行為分析，提供可量測的理論框架來理解與預測長距離推理中的代理人穩定性與失效模式。

## 應用情境與實務影響

指導更穩健的 LLM 代理人架構設計；改進長時程任務中的錯誤檢測與復原機制；為代理人基準提供新的評估維度。

## 補充細節

論文於 2026-09-16 提交至 arXiv (ID: 2609.17419v1)。研究團隊提出世界模型科學框架，將代理人內在狀態軌跡與基準真實狀態對齊，測量壓力累積、錯誤 avalanche、時間依賴性、局部-全域不匹配、有界發散、信念盆地轉移等關鍵指標。在橫跨六個任務類別的 22 項實驗中驗證發現：(1) 即使全域狀態解編碼後失真，局部有效動作仍可執行；(2) 壓力達閾值時觸發 abrupt 系統性失效；(3) 錯誤序列展現長時程相關性，非馬可夫過程；(4) 依賴深度影響誤差傳播模式；(5) 較長時間窗口支持規模更大的錯誤 avalanche 事件。此工作为理解 LLM 代理人在複雜推理任務中的行為提供了第一個基於動力系統的理論框架。
