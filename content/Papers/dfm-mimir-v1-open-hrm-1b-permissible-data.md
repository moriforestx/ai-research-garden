# DFM Mimir v1: An Open HRM Delivering Frontier Performance at 1B Parameters Using Only Permissible Post-Training Data

## 基本資訊

- 發布日期：2026-08-13
- 研究主題：大型語言模型與自然語言處理 / LLM & NLP
- 主要來源：https://arxiv.org/abs/2608.13517

## 概要

發布 DFM Mimir v1，一個基於層級推理模型（HRM）架構的 10 億參數語言模型，從頭訓練且僅使用允許的後訓練數據（161 個資料集混合）。在英語 20 個基準測試中超越原始 HRM-Text 1B，並與 Qwen 3.5 4B、Gemma 4 E2B 等更大模型競爭；同時為丹麥語設立新 SOTA。模型開源於 Hugging Face (danish-foundation-models/DFM-Mimir)，展示小參數量、開放數據也能達到前沿性能。

## 核心價值

證明 1B 參數的 HRM 架構模型在開放許可數據上訓練即可達到前沿水平，大幅降低開源 LLM 開發門檻。

## 應用情境與實務影響

為資源受限研究者提供可複製的開源 LLM 訓練範式；推動小模型高效能、數據合規的發展方向。
