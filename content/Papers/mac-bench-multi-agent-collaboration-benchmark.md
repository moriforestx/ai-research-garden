# MAC-Bench: Benchmarking Multi-Agent Collaboration via Interconnected Tasks

## 基本資訊

- 發布日期：2026-11-01
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://arxiv.org/abs/2611.01728

## 概要

提出 MAC-Bench，針對多代理人協作設計的基準測試，透過挖掘現有基準的可重用結構並重組，構建包含業務營運與軟體工程領域的相互關聯任務。任務涵蓋多樣依賴、整合與共享資源約束，能區分部分進度與完整解決。

## 核心價值

首個系統性構建「相互關聯任務」的多代理人協作基準，支援任務結構的組合式擴展，並提供針對性檢查協作關係違反的影響。

## 應用情境與實務影響

多代理人系統開發者可用於評估協作能力；研究者可基於此基準改進協作策略、規劃與執行機制。企業級多代理人應用（如業務流程自動化、軟體工程協作）有了標準化評估工具。

## 補充細節

作者：Zerui Chen、Qinggang Zhang、Qichuan Liu、Zhishang Xiang、Zhimin Wei、Yunbo Tang、Zhuo Li、Jinsong Su、Zhihong Zhang。arXiv:2611.01728v2，2026年11月1日提交，11月7日更新。在兩種 LLM 骨幹上測試，Meta-Team 表現最佳，但無配置解決超過 6.25% 任務，顯示多代理人協作仍具挑戰。任務庫涵蓋局部協作模式與全局任務圖兩個尺度。
