# Decentralized Multi-Agent Coordination and Communication in Shared Codebases

## 基本資訊

- 發布日期：2026-10-30
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://arxiv.org/abs/2611.00314

## 概要

提出 ParallACT 基準測試，研究無協調器的多智能體程式設計任務。包含互補型與矛盾型任務：互補任務需共享介面才能有效合併；矛盾任務需編輯相同程式碼但方式不相容。比較單智能體預言機與多智能體設定（執行順序、可見度、對方感知、通訊管道）。

## 核心價值

預言機解決大多數任務，但並行智能體顯著較差，尤其矛盾任務（如 Claude Code + Opus 4.8 從 62% 降至 16%）。僅告知對方存在無顯著幫助，通訊管道僅回收小部分效能並增加 token 成本。

## 應用情境與實務影響

隔離出多智能體獨立開發共享代碼庫的核心協調難題，提供受控測試平台評估協調策略成本效益，隨著多智能體程式設計成常態將愈發重要。
