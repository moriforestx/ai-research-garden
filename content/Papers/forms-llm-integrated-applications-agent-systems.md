# Forms of LLM-Integrated Applications from LLM-Chats to Autonomous AI Agent Systems

## 基本資訊

- 發布日期：2026-10-01
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://arxiv.org/abs/2610.11899

## 概要

該綜述論文系統性歸納 LLM 整合應用的七種反覆形式：LLM 對話、自訂代理、檢索增強生成 (RAG)、AI 增強工作流、副駕駛、編碼代理、代理式 RAG。以四大結構維度（架構模式、執行控制與使用者介入點、工具存取範圍、監控維度）為共同詞彙，逐一剖析各形式的技術特徵、部署樣態與風險面向。文中並對照 Microsoft 365 Copilot、GitHub Copilot、SAP Joule、Salesforce Einstein、Siemens Industrial Copilots 等商業系統實證分類。

## 核心價值

提供業界首個統一分類框架，將雜沓的代理產品納入結構化光譜，助開發者依維度選型、審計與治理。

## 應用情境與實務影響

適用於架構決策、合規審查、代理平台採購評估、以及自研代理系統的分層設計參考。
