# Matryoshka Agent: Unfolding Sub-Agents for Long-Horizon Machine Learning Engineering

## 基本資訊

- 發布日期：2026-07-25
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://arxiv.org/abs/2607.25090

## 概要

提出 Matryoshka Agent 架構，將長時程機器學習工程任務分解為可疊套的子代理人層級，每層負責不同抽象層次的規劃與執行。在 Kaggle 風格競賽基準上驗證，展現比單一代理人更穩定的長程推理與錯誤恢復能力。

## 核心價值

仿生套娃式分層代理人架構，將 12 小時長時程 ML 工程任務拆解為策略規劃、程式生成、除錯驗證三層子代理人協作。

## 應用情境與實務影響

為自動化 ML 工程（AutoML、Kaggle 競賽、模型優化管線）提供可擴展的代理人框架，降低長時程任務的失敗率與人工介入需求。

## 補充細節

arXiv:2607.25090v1 [cs.AI]，2026-07-25 提交。實驗環境為 Dojo Agent 基準，代理人擁有完整互動歷史與無限輸入/輸出 token。程式碼待開源。
