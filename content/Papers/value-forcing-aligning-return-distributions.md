# Value Forcing: Aligning Return Distributions at All Noise Levels

## 基本資訊

- 發布日期：2026-11-01
- 研究主題：AI 綜合動態 / General AI Updates
- 主要來源：https://arxiv.org/abs/2611.02160

## 概要

提出 Value Forcing 方法，利用流匹配估算回報分佈，在有限資料下實現準確的價值學習。核心洞見是在每個雜訊層級強制貝爾曼一致性，提取更豐富的學習訊號。

## 核心價值

在離線強化學習的 26 個長時程任務中優於既有價值學習方法，資料有限時增益特別明顯。

## 應用情境與實務影響

適用於機器人等真實世界應用，解決資料稀疏、獎勵訊號微弱時的價值函數學習難題。
