# GPT-5.6 Sol Ultra Proves Cycle Double Cover Conjecture: LLM Solves 50-Year Graph Theory Problem

## 基本資訊

- 發布日期：2026-07-10
- 研究主題：大型語言模型與自然語言處理 / LLM & NLP
- 主要來源：https://cdn.openai.com/proof-cycle-double-cover.pdf

## 概要

OpenAI 宣稱其 GPT-5.6 Sol Ultra 模型在不到一小時內證明了圖論中著名的「迴路雙重覆蓋猜想」，這是一個懸而未決 50 年的開放問題。OpenAI 發布了三頁證明、兩頁生成提示詞，以及 Lean 形式化驗證代碼（openai/cdc-lean）。該猜想由 Szekeres 與 Seymour 於 1970 年代獨立提出，詢問每個無橋圖是否存在覆蓋每條邊恰好兩次的迴路集合。

## 核心價值

首次有大型語言模型自主解決頂級數學開放問題，展示 LLM 在形式化數學推理與定理證明上的突破性能力，並附帶完整提示詞與形式化驗證流程。

## 應用情境與實務影響

確立 LLM 輔助數學研究的新範式：從猜想生成證明、提示詞工程、形式化驗證到同行審查的完整鏈路，將加速數學發現並重塑證明驗證標準。

## 補充細節

證明使用最多 64 個並發子代理，採獨立探索策略避免路徑依賴。Lean 形式化針對有限無環無橋多重圖完成。數學界正進行驗證（MathOverflow、Hacker News 討論熱烈）。來源：OpenAI 官方 CDN、Wikipedia、Wolfram MathWorld、MathOverflow。
