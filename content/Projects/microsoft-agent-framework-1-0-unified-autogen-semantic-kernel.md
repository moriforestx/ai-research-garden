# Microsoft Agent Framework 1.0: AutoGen 與 Semantic Kernel 統一 SDK

## 基本資訊

- 發布日期：2026-04-03
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://www.developersdigest.tech/blog/microsoft-agent-framework-developer-guide-2026

## 概要

Microsoft 於 2026 年 4 月 3 日發布 Microsoft Agent Framework 1.0，將 AutoGen 與 Semantic Kernel 兩大開源專案整合為單一生產級 SDK。框架統一了 Semantic Kernel 的企業級模型連接器、記憶與工具呼叫基礎，以及 AutoGen 的創新多代理人編排模式，提供穩定 API 與長期支援承諾。原生支援 MCP (Model Context Protocol) 與 A2A (Agent2Agent) 協定，Python 與 .NET 同步達 GA。

## 核心價值

結束 Microsoft 三年來雙軌並行的代理人開發分裂局面，單一套件涵蓋從模型整合到多代理人編排的完整棧，降低遷移與維運成本。

## 應用情境與實務影響

新專案可直接採用統一 SDK，避免在 Semantic Kernel、AutoGen、AG2 社群分支間抉擇；內建 MCP/A2A 互通、Foundry Hosted Agents 託管服務（按用量計費、支援縮放至零），加速企業級代理人應用上線。

## 補充細節

Python 與 .NET 同步 1.0 GA，宣告 AutoGen 與 Semantic Kernel 進入維護模式（關鍵修補持續至少一年）。GitHub: microsoft/agent-framework。Build 2026 另釋出 Agent Harness、GitHub Copilot SDK 與 Claude Agent SDK 連接器、多代理人編排模式穩定版。
