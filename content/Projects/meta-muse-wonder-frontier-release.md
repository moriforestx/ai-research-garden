# Meta 發布首個前沿模型 Muse Wonder 系列

## 基本資訊

- 發布日期：2026-10-12
- 研究主題：AI 綜合動態 / General AI Updates
- 主要來源：https://techcrunch.com/2026/10/12/meta-releases-its-first-frontier-model-muse-wonder

## 概要

Meta Superintelligence Lab 於 2026 年 10 月 12 日正式發布 Muse Wonder 與 Muse Wonder Full 兩款前沿模型，為 Meta 首次嘗試推出最先進（frontier-class）模型。模型在 Prometheus 資料中心訓練，透過 Meta Model API 以 $4/百萬輸入、$20/百萬輸出定價提供；Muse Wonder Full 僅限 Muse Code 訂閱者使用。兩款模型亦將驅動 Muse agent 體驗。

## 核心價值

Meta 正式進入前沿模型競爭行列，標誌其 AI 策略從輕量模型轉向最先進能力，並整合至消費級 Muse 應用與開發者 API。

## 應用情境與實務影響

開發者可透過 Meta Model API 即時存取前沿模型；企業與專業用戶獲得新的高階推理、程式編寫、多步驟任務選項，定價與 GPT-6 Sol、Opus 5.5 相當。

## 補充細節

TechCrunch 報導確認發布日期為 2026-10-12（週一）。Meta 官方部落格 (research.meta.ai/blog/muse-wonder) 同步發布技術細節，強調 CBRN/網安防護與負責任釋出框架。
