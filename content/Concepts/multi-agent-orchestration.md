# Multi-Agent Orchestration

## 定義

協調多個專業化 Agent 協同完成複雜任務的系統工程學科。核心挑戰：任務分解與分配、狀態同步與一致性、通訊協議標準化、失敗恢復與容錯、成本控制、可觀測性。主流編排模式：圖基礎（LangGraph）、角色協作（CrewAI）、對話式（AutoGen）、SDK 原生（OpenAI Agents SDK、Google ADK）。成熟度模型：L1 單一 Agent → L2 線性工作流 → L3 分支路由 → L4 圖狀編排 → L5 自適應多 Agent 系統。

## 為什麼重要

- 單一 Agent 無法處理跨領域、長流程、高可靠性要求的企業級任務
- 編排層是 Agent 系統的「作業系統」，決定系統上限
- 缺乏編排導致 Agent 互相衝突、無限循環、成本失控、難以除錯
- 2025-2026 年是編排從研究走向生產的關鍵窗口期
