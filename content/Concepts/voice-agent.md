# Voice Agent

## 定義

以語音為主要交互介面的 AI Agent，具備語音識別（STT）、自然語言理解（NLU）、對話管理、自然語言生成（NLG）、語音合成（TTS）完整鏈路能力。區別於傳統 IVR 或語音助手，Voice Agent 擁有 LLM 級別的推理規劃能力，能執行多步驟任務、調用工具、維護長期記憶、處理打斷和多輪對話。

## 為什麼重要

- 語音是人類最高效、最自然的交流方式，Voice Agent 降低使用門檻至零（無需識字、打字、看屏）
- OpenAI 新音頻 API、Hugging Face Voxtral/Cohere Transcribe 同步商業化，基礎設施成熟
- 應用場景爆發：客服替代、車載助手、無障礙輔助、老人陪護、現場作業指導、語言學習
