# OpenAI 發布 Presence：企業級 AI 代理產品，支援語音與聊天代理、系統整合與人工介入升級機制

## 基本資訊

- 發布日期：2026-07-22
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://openai.com/index/introducing-openai-presence

## 概要

OpenAI 官方發布 Presence，專為企業設計的 AI 代理產品，經多年企業級客戶驗證。Presence 讓 AI 代理能回答問題、解決議題、使用公司系統、執行核准動作，並在需要時升級轉接人工。內建策略、防護欄位與升級規則，驗證準確性與效能。支援語音與聊天代理，搭配 GPT-Live-1 模型提供即時語音互動。同日週期內 OpenAI 另推出 ChatGPT 小企業方案 (7/21)、Health 功能 (7/23)、Partner Network (6/14)。

## 核心價值

OpenAI 將多年企業級代理實戰經驗產品化，提供開箱即用的可信任代理平台，降低企業自建代理系統的門檻與風險。

## 應用情境與實務影響

企業可快速部署合規、可審計的客服與內部工作流代理；語音代理支援即時電話/語音互動；升級機制確保關鍵決策有人工把關；整合既有系統與 API。

## 補充細節

官方部落格 openai.com/index 發布，2026-07-22。Presence 定位為「battle-tested」企業產品，強調 policies、guardrails、escalation rules 三大治理機制。同期產品：ChatGPT Small Business (7/21)、Health (7/23)、Partner Network (6/14)、GPT-Live-1 API 整合。
