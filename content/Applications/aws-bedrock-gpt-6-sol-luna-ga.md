# AWS Amazon Bedrock 正式支援 OpenAI GPT-6 Sol 與 GPT-6 Luna，提供企業級部署選項

## 基本資訊

- 發布日期：2026-09-22
- 研究主題：AI 應用與部署 / AI Applications & Deployment
- 主要來源：https://aws.amazon.com/about-aws/whats-new/2026/09/openai-gpt-6-sol-luna-on-amazon-bedrock

## 概要

AWS 官方「What's New」公告宣布 OpenAI GPT-6 Sol 與 GPT-6 Luna 於 Amazon Bedrock 正式達到一般可用性 (GA)。GPT-6 系列至此包含 Astra、Sol、Luna 三款模型，讓團隊可在智力、速度與成本間彈性取捨。Sol 定位為日常複雜任務與軟體開發主力模型，內部事實性評估錯誤率約為 GPT-5.6 的一半；Luna 則為高流量專用任務的最高效能模型。Bedrock 提供單一 API、統一計費、內建護欄、模型調用審計等企業級治理功能。

## 核心價值

頂級閉源模型登陸主流雲平台托管服務，標誌企業不再需自建推理基礎設施即可以合規方式大規模採用最新模型。

## 應用情境與實務影響

企業可透過 Bedrock 統一採購、治理與監控 OpenAI 模型，簡化合規與安全審查；開發者獲得更多成本/效能選擇以優化生產負載。

## 補充細節

發布日期 2026-09-22。同週 AWS Weekly Roundup (2026-09-28) 另確認 Claude Opus 5.5 亦已上架 Bedrock。模型存取、計費、護欄、調用審計皆由 Bedrock 原生支援。GPT-6 Sol/Luna 亦同步於 ChatGPT Work、Codex、GitHub Copilot 可用。
