# NVIDIA 宣佈收購 Hugging Face，整合推理部署基礎設施與開放模型生態

## 基本資訊

- 發布日期：2026-09-03
- 研究主題：AI 應用與部署 / AI Applications & Deployment
- 主要來源：https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face

## 概要

NVIDIA 於 2026 年 9 月 3 日宣佈同意以 129.3 億美元收購 Hugging Face。雙方將整合 NVIDIA 的加速運算基礎設施（DGX Cloud、TensorRT-LLM、NIM 微服務）與 Hugging Face 的開放模型平台（Hub、Inference Endpoints、TGI、Spaces），目標為：擴大開發者對 AI 的存取、強化平台可靠性與安全性、保持開放生態系統的多雲與多加速器支援。收購後 Hugging Face 將保持品牌獨立運營，持續支援全生態系的開放權重模型。

## 核心價值

將模型發現、微調、部署全鏈路納入單一加速運算堆疊，解決企業在基礎設施前期成本、推理優化複雜度、多雲部署碎片化等痛點；NIM 微服務與 TGI 整合將推動標準化、高能效的生產級推理服務。

## 應用情境與實務影響

企業可透過 Hugging Face Hub 以 Serverless 方式即時存取 NVIDIA 優化的 NIM 微服務（OpenAI API 相容），無需自建 GPU 叢集；開源社群受益於 DGX Cloud 算力擴充與 TensorRT-LLM 效能優化下放；多雲策略與開放模型承諾降低廠商鎖定風險。

## 補充細節

交易金額：129.3 億美元。NVIDIA CEO 黃仁勋 強調將保持 Hugging Face 開放生態定位，支援多雲（AWS、GCP、Azure）與多加速器（GPU、TPU、NPU）。關鍵技術整合點：1) NIM 微服務標準化部署介面，2) TensorRT-LLM 融入 TGI 提升推理吞吐，3) DGX Cloud 提供彈性推理算力池，4) Enterprise Hub 組織獲得專屬 NIM API 存取。同期競合動態：Google Vertex AI、AWS Bedrock、Azure AI Foundry 持續擴充模型目錄與代理人工具鏈。來源：NVIDIA 官方部落格（Jensen Huang 簽名）、NVIDIA 中文部落格（黃仁勳簽名）、多方財經媒體跟進報導。
