# Claude Duet — Proactive AI Agent App

## 基本資訊

- 發布日期：2026-10-21
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://claude.com/resources/articles/claude-duet

## 概要

Anthropic 於 2026-10-21 正式推出 Claude Duet 研究預覽版，面向美國 Pro/Max 訂閱用戶開放候名單。Duet 是獨立 App（iOS、Android、claude.ai），基於 Claude Opus 5.5 構建，具備主動代理能力：每日早報、監控連接應用（6,000+ 整合含 Gmail、Slack、QuickBooks、Shopify）、後台持續執行任務、敏感操作需用戶確認。定位專業人士與小企業主，解決工作流過載問題。

## 核心價值

Anthropic 首個面向消費者的主動式代理產品，標誌 AI 代理從「被動回應」進入「主動協助」階段；與 OpenAI、Meta 代理產品形成直接競爭。

## 應用情境與實務影響

專業用戶可委派排程、財務預測、Web 應用構建等重複性工作；企業級整合支援 6,000+ SaaS，降低代理落地門檻。研究預覽階段免費包含於 Pro/Max 方案。
