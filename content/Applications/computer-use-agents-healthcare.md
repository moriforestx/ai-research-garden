# 推進醫療團隊電腦使用代理：從患者訊息到 MRI 授權的端到端自動化

## 基本資訊

- 發布日期：2026-11-16
- 研究主題：AI 代理人 / AI Agents
- 主要來源：https://openai.com/index/advancing-computer-use-for-healthcare-teams

## 概要

OpenAI 於 2026 年 11 月 16 日發布醫療場景電腦使用代理進展，展示從患者訊息自動生成 MRI 授權請求的端到端工作流。代理能在現有醫療軟體系統中操作瀏覽器、填寫表單、跨系統傳輸資訊，減少醫療團隊在行政作業上的時間投入。基於 OpenAI 電腦使用能力與 Agents API，提供網站存取審批與登入處理機制。同期發布 ChatGPT Wallet for agents（11/13）與醫療版 ChatGPT 更新。

## 核心價值

首個針對高監管醫療場景的電腦使用代理實戰部署案例，驗證代理在合規、安全要求極高環境下的實用性。

## 應用情境與實務影響

醫療機構可透過 OpenAI API 與電腦使用指南構建類似代理，自動化授權申請、病歷錄入、保險理賠等跨系統作業，讓醫護人員專注臨床照護。

## 補充細節

代理在 OpenAI 託管瀏覽器中執行，支援網站存取審批與應用層登入處理。配合 Responses API 內建工具（網頁搜尋、檔案搜尋、電腦使用）與 Agents SDK 沙箱編排。案例聚焦 MRI 事前授權流程，展示多步驟、多系統交互的自動化能力。
