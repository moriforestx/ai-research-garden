# ChatGPT Enterprise 登上 AWS Marketplace，企業採購路徑再擴展

## 基本資訊

- 發布日期：2026-11-09
- 研究主題：AI 綜合動態 / General AI Updates
- 主要來源：https://emergent.sh/news/chatgpt-enterprise-now-available-aws

## 概要

OpenAI 於 2026-11-09 正式將 ChatGPT Enterprise 推上 AWS Marketplace，包含 ChatGPT Enterprise、ChatGPT for Healthcare、ChatGPT for Financial Services 三大方案，功能與直接向 OpenAI 購買完全對等。企業可透過既有 AWS 帳單採購，消費額計入 AWS EDP 或 PPA 承諾，簡化採購流程。

## 核心價值

首次讓企業透過雲端市場直接採購頂級 AI 企業方案，大幅降低大型組織引入生成式 AI 的採購與合約門檻。

## 應用情境與實務影響

採購、法務、財務三方流程合一，加速企業從評估到全面部署的時程；對已有 AWS 承諾消費的大型組織極具吸引力。

## 補充細節

AWS Marketplace 列表由 OpenAI 直接發布，Matt Yanchyshyn (VP AWS Marketplace) 指出企業希望不增加採購層級即可跨團隊落地 AI。定價採私有報價模式，需與 OpenAI 或 AWS 客戶經理洽談。啟動客戶包含 OutSystems 與 Swissquote。
