# Spectro Cloud PaletteAI Inference Launchpad：本地優先推理解決方案

## 基本資訊

- 發布日期：2026-07-21
- 研究主題：AI 應用與部署 / AI Applications & Deployment
- 主要來源：https://www.spectrocloud.com/news/spectro-cloud-launches-paletteai-inference-launchpad

## 概要

Spectro Cloud 於 2026 年 7 月 21 日正式發布 PaletteAI Inference Launchpad，為企業提供開箱即用的本地優先 AI 推理平台，宣稱可降低高達 70% 的 Token 成本。解決方案整合政策式路由、計量計費與治理功能，支援 AMD Instinct GPU 與 Supermicro 硬體，適用於受監管產業、主權雲與邊緣環境的資料駐留與合規需求。同步於 AMD Advancing AI 大會 (7/22-23) 現場展示。

## 核心價值

提供廠商中立的 Kubernetes 原生推理編排層，解決企業在私有/混合雲部署 LLM 推理的成本與治理難題。

## 應用情境與實務影響

企業可透過 Palette 平台統一管理多叢集推理工作負載，支援 AMD、NVIDIA 異構 GPU，內建政策路由自動將編碼任務導向本地模型、複雜推理導向前沿模型，降低對公有雲 API 的依賴。

## 補充細節

官方新聞稿發布日期 2026-07-21。AMD 新聞室同步發布聯合公告 (AMD Instinct Coder 方案)。Spectro Cloud 於 2026-07-15 完成 1 億美元 D 輪融資，加速生產級 AI 採用。PaletteAI Inference Launchpad 為 PaletteAI 產品線擴展，專注推理階段成本優化。
