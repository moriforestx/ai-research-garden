# Natural-Language Policies to Executable Decisions: An Interpretable Large Language Model Framework

## 基本資訊

- 發布日期：2026-06-22
- 研究主題：AI 應用與部署 / AI Applications & Deployment
- 主要來源：https://arxiv.org/abs/2608.26124

## 概要

提出生產級 LLM 定價系統，嚴格劃分決策邊界：LLM 負責結構化抽取與有界策略/路徑選擇，所有數值定價含總價計算由確定性程式執行。策略編譯為可解釋條件樹，支援無程式碼變更的新條款與規則演進，並產出可審計產物供人工介入。定期在日誌軌跡上微調進一步提升樹歸納與路徑匹配。已在市營觀光企業 7 大風景區、12 業類、1500+ 操作員、1000+ 活躍策略部署六個月，處理 3960 筆訂單，團隊從 15-20 人縮減至 3 人，單筆處理時間從 10 分鐘降至 2 分鐘內。

## 核心價值

罕見的 LLM 生產部署實證研究，展示「LLM 做語義理解、確定性程式做數值計算」的混合架構如何兼顧靈活性與可靠性，並量化呈現人力與效率效益。

## 應用情境與實務影響

直接可複用於電商動態定價、保險核保、金融產品報價、物流運費計算等需結構化策略與數值精確性的場景；架構強調可審計性與人工介入，符合金融級合規需求。
